# ADR-0695: 가상 계좌의 검증 수익성 선택과 사후 평가

Status: Accepted · 2026-10-07

사용자는 가상 계좌를 실전의 선행 단계로 보고 수익성이 검증된 매매 기준을 선택·기록·평가하도록 개선을 요청했다. ADR-0694의 전체 신호 추종·종목 코드 우선 배정을 다음 정책으로 교체한다. 실주문 연결은 하지 않는다.

- 거래일 첫 장중 전체 스냅샷에서 현재 연결된 `ACTIVE` 규칙을 비교한다. 기존 학습·후반 확인 요건(각 10건·3일 이상, 순수익·대조군 우위 양수)을 유지하고 당일 00:00 이전 확정 결과로 만든 당일 연구 자료만 사용한다. 발명 지표는 기존 생성 후 검증을 그대로 사용한다. 검증 기간 평균 순수익률 순, 동률이면 일당 대조군 우위·규칙 키 순으로 하나를 선택한다. 서로 다른 D1/D3/D5의 총수익 비교이며 기간당 수익 최대화는 아니다.
- 후보·순위·표본 지문·규칙·선택 시각·자료 마감·평가 시각을 계좌에 매일 추가하고 변경·삭제를 금지한다. 같은 날은 재시작해도 선택을 바꾸지 않는다. 자료 부재/미래/전일 자료는 선택 대기 후 새 자료에서 재시도하며, 유효한 당일 자료에 충족 규칙이 없으면 당일 미선택을 기록한다.
- 원본 신호 엔진이 **선택한 규칙으로** 새로 진입한 거래만 계좌 후보로 받는다. 단순히 같은 종목이 규칙에 해당한다는 이유로 별도 거래를 만들지 않는다. 신호의 동결 근거·평가 시각·검증 성적을 선택 기록과 대조한다. 이미 보유 중이거나 계좌 시작 전 진입한 원본 신호는 소급하지 않는다. 검증 순위를 조회한 시점 이후에 발생하는 계좌 거래만 사후 성과에 포함한다.
- 탐색 신호는 1주 연구에 유지하고 계좌에서는 제외한다. 기존 `includeExploration` 설정값과 과거 거래는 보존하되 신규 매수에는 적용하지 않음을 화면에 표시한다. 새 계좌의 탐색 포함 요청은 거절한다. 보유 종목의 매도는 원본 거래의 진입 당시 고정 매도 정책으로 계속 처리한다. 계좌 선택 실패나 매수 정지가 매도를 중지시키지 않는다.
- 같은 스냅샷에서 계좌 기준·가격·중복 조건을 통과한 종목끼리 현재 현금을 균등하게 나눈다. `min(현금/후보 수, 비용 차감 청산 자산×종목 상한)`을 원화 소수 둘째 자리에서 버린 예산으로 정하고 비용 포함 정수 수량을 산출한다. 종목 코드에 따른 선점은 없으며 잔여 현금을 뒤 종목에 재배분하지 않는다. 매도 대금 처리는 매수 예산 계산보다 먼저 한다.
- 선택에 사용한 D기간 검증 통계는 계좌의 관측 매도 수익과 다르다. 검증 성적으로 최상위 후보를 선택했으므로 그 성적을 독립 최종 평가로 주장하지 않는다. 계좌의 실제 가상 체결만으로 순손익·거래당 순수익·평균 이익/손실·총이익/총손실·승률을 계산하고 일별 선택 기록과 연결한다. 거래당 평균은 동일 거래 가중이며 계좌 수익률과 별개다.
- 계좌 최대 낙폭은 비용 차감 청산 자산을 신선한 가격으로 평가한 관측에만 갱신한다. 새 계좌는 초기 예수금부터, 기존 계좌는 업그레이드 이후 첫 유효 평가부터 집계한다. 집계 시작·마지막 평가·횟수·고점·최대 낙폭을 보존하고 과거 구간을 추정하지 않는다. 관측 사이의 가격·호가 잔량·부분 체결·D+2 결제와 실계좌 연결은 범위 밖이다.
- 선택 버전 `validated-net-v1`과 주문의 선택 ID는 별도 계좌 원장에 남긴다. 기존 주문은 그대로 읽고 매도할 수 있다. 기본 관측·지표 연구·공급자 및 브로커 경계는 바꾸지 않는다.

검증: 실제 신호 생성 경로 연계, 최고 검증 순수익 선택, 불충분/음수/미래/중복 근거 배제, 같은 날 고정·재시작·다음 거래일 교체, 동시 균등 예산·현금 보전, 기존 보유 매도, 정책·체결 원장 불변, 계좌 사후 손익·관측 낙폭·화면 및 알림 근거 분리.

복구: 신규 계좌 매수를 정지한 상태에서 정책 변경을 되돌린다. 선택·주문·위험 기록을 삭제하거나 기존 체결을 다시 계산하지 않는다. 구 버전 코드가 새 기록을 덮어쓰지 않도록 계좌 처리를 중지하거나 호환 읽기를 유지해야 한다.
