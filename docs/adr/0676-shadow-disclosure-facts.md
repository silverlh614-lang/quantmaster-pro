# ADR-0676: Shadow 상장기업 공시 수집과 사실 관측

@responsibility Record factual disclosure provenance for independent Shadow research.

## Status

Accepted

## Context

- 2026-09-16 운영 조회에서 알림용 최근 200건이 비상장·펀드 공시로 채워졌다. 고속 조회와 목록 프록시는 잘못된 `sort=rcp_dt`로 OpenDART 상태 100을 받았고, 일반 알림은 해석한 종목 코드 대신 원시 빈 코드를 저장했다.
- 공시 제목의 호악재 추정만으로 규모·조건·실제 주가 영향을 확정할 수 없다. 직접 공시와 간접 공급망 자료를 구분할 근거와 수집 범위가 필요하다.

## Decision

- `dartDisclosureClient`는 OpenDART 목록을 코스피(Y)·코스닥(K)별로 조회한다. 최근 72시간에 걸친 한국 날짜 범위, `sort=date`, `last_reprt_at=N`, 페이지당 100건을 사용한다. 시장당 50페이지·전체 20초·요청당 최대 5초로 제한하며 미완료·잘못된 행·통신 오류를 부분 수집 또는 조회 불가로 노출한다.
- `paperDisclosureCollection`은 5분 재조회 간격과 중복 실행 방지를 적용한다. 알림용 저장소와 분리한 `paper-disclosures.json`에 최근 접수일 14일 자료를 원자적으로 저장한다. 손상된 원본은 덮어쓰지 않는다. 조회 실패에도 기존 자료와 오류 상태를 반환하여 가격 관측을 계속한다.
- 접수번호·기업 코드·제목·접수일·최초 수집 시각을 저장하고 종목 연결 시각을 별도로 기록한다. 같은 접수번호의 최초 제목·시각은 바꾸지 않는다. 동일 접수번호·종목·제목·접수일의 기존 알림에 검증 가능한 더 이른 시각이 있으면 보존한다. 뒤늦은 종목 연결은 연결 이후에만 사용한다.
- 새 공시는 현재 관측 후보·기존 뉴스 후보·보유 가상 종목에 연결한다. 전체 상장기업 공시 목록으로 가격 관측 후보를 무조건 확대하지 않는다. 일반·고속 폴러의 한국 날짜, 정렬 인자, 해석한 종목 코드 저장도 수정한다.
- 기존 목록 프록시의 `B001` 호출은 OpenDART의 상세 유형 필드로 전달하고, 빈 유형은 필터를 생략한다. 빈 문자열을 필터로 보내 실제 공시가 있어도 빈 결과를 받는 문제를 방지한다.
- `news-facts-v1`은 직접/간접/미확인 관계와 공시 제목의 사건 유형, 정정·철회 여부, 원문 링크를 수집 시점에 기록한다. 원문 금액·조건 추출과 실제 호악재 확정은 하지 않는다. 접수일은 날짜이며 실제 발표 시각으로 변환하지 않는다.
- 기본 관측과 v2 진입에 사실 정보를 복사해 고정한다. 사건별로 검증된 진입 직전 거래일 수급 비율과 정확한 D1/D3/D5 순수익률을 독립 집계한다. UI·Telegram 분석에 근거를 표시한다. 신규 뉴스나 수급 조건을 BUY 자격에 추가하지 않는다.

## Consequences

- 이후 진입부터 사건별 표본이 쌓인다. 과거 진입은 새 분류로 소급 보정하지 않으며, 직접 사건별 표본이 없는 기간은 집계 대기로 표시한다.
- 사건별 단순 평균은 인과 관계나 매매 성과를 증명하지 않는다. 한 진입이 여러 사건 그룹에 포함될 수 있고, 정정·철회는 별도 그룹으로 비교한다.
- 조회 범위·완료 상태·종목 연결/미연결 수를 확인할 수 있다. 공급자 제한으로 일부 페이지가 누락되면 재조회까지 부분 상태를 유지한다. 장기 장애 복구의 무제한 과거 재수집은 범위에 포함하지 않는다.

## Guardrails

- 신규 수집은 공시 읽기 전용이며 주문·실거래·수동 Telegram 발송을 실행하지 않는다. 기존 가격 수집·전략 v2·비용·청산 기준은 유지한다.
- 페이지 처리, 시간·종목 검증, 저장 후 재시작, 실패 격리, 과거 분류 미소급, 진입 복사, API·화면·메시지 회귀를 테스트한다.
- 공급자 계약: [OpenDART 공시검색 공식 안내](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019001).
