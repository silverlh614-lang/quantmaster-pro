# ADR-0672 — 매매 시그널과 학습·연구 채널 연결

상태: Accepted · 2026-09-13

사용자 요청: 매매 시그널을 유지하고 학습·연구와 연결한다. ADR-0671의 새 보고가 개인 DM에 집중되어 있던 경로를 기존 4채널에 배분한다.

- CH1(signal/TRADE): 새 Shadow 진입·청산. CH2(분석/ANALYSIS): 같은 종목·진입일의 진입 고정 뉴스·추세 유형, 표본·진입일 수, 기본 관측/과거 재현 출처, 선택 보유기간과 당시 평균 성과, 해당 청산 결과. CH3(정보/INFO): 거래일 08:45 준비·뉴스. CH4(시스템/SYSTEM): 거래일 16:10 성과·학습과 일요일 19:00 연구. 운영 중단·복구는 개인 DM을 유지한다.
- 봇은 전체 관측·전략 원장의 조회 결과를 사용한다. 화면의 최근 200건 제한 때문에 오래된 진입의 청산 시그널이나 당일 집계가 누락되지 않게 하며, UI의 기본 조회 제한은 유지한다.
- 기본 관측 표본과 사용 가능한 과거 뉴스 자료로 학습하는 현행 전략을 그대로 사용한다. 전략 성과는 별도 원장에 누적한다. 7개 조건의 탐색 연구를 새 매매 조건이나 자동 승격으로 바꾸지 않는다. Gate·총점·레짐 제한을 복원하지 않는다.
- 기존 `paper_bot` 예약을 유지하고 매매 이벤트를 최대 5개씩 나눈다. 모든 이벤트를 포함하며 CH1/CH2는 목적지별 별도 ID·발송 상태를 저장한다. 한 채널 실패가 다른 채널 성공을 재전송시키지 않는다. `dispatchAlert`의 immediate·cooldownMs=0 경로를 사용하고 양의 메시지 ID만 성공으로 기록한다. 실패·재시작·만료 정책은 ADR-0671을 유지한다.
- `paper-bot.json`의 channel은 선택 필드다. 기존 목적지 없는 메시지는 원래 DM으로 처리하고 과거 성공/매매를 재방송하지 않는다. 원장 schemaVersion과 kind는 유지한다. `/paper_bot`에서 채널별 성공·대기·실패를 확인한다.
- 수집·학습·매매 원장·실주문 경로 변경 없음. 시장 데이터 추가 호출 없음. 검증은 외부 전송을 mock한 일정·부분 실패·실제 라우터·채널 권한 설정·재시도·길이·근거 연결·원장 호환 검사로 한다. 복구는 이 커밋을 revert하며 신규 목적지 필드는 구버전에서도 읽을 수 있다. 롤백 뒤 남은 미발송 건은 기존 DM 경로로 처리된다.
