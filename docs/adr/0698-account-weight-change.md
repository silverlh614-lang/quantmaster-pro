# ADR-0698: 가상 계좌 종목당 비중의 이후 매수 변경

Status: Accepted · 2026-10-09

ADR-0696은 계좌 시작 때 고정한 종목당 비중으로 동시 보유 상한(`floor(100 ÷ 비중)`)과 매수 배정액을 정했다. 시작 후에는 비중을 바꿀 방법이 없어 20%(5종목)로 시작한 계좌는 넓은 규칙의 많은 신호 중 5개만 섞인 순서로 사서 계좌 성과가 규칙의 질보다 선택 운을 더 반영했다. 사용자 선택(2026-10-09, A안)에 따라 ADR-0696의 "계좌 시작 때 고정한 비중을 그대로 쓴다" 항목을 다음으로 교체한다. 실주문 연결은 하지 않는다.

- 계좌 원장에 선택 필드 `weightChanges`(변경 시각·종목당 비중 1~100%)를 시간순 추가 전용으로 기록한다. 시작 설정(`config`)은 바꾸지 않는다.
- 각 스냅샷의 매수는 그 시각 이전의 마지막 변경 비중(없으면 시작 비중)으로 상한과 배정액을 계산한다. 같은 비중으로의 재변경은 기록하지 않는다.
- 기존 주문·체결·보유·선택 기록은 다시 계산하지 않는다. 비중을 줄여 생긴 자리는 남은 현금 안에서 이후 매수에 쓴다. 비중을 늘려 보유 수가 새 상한보다 많으면 매도하지 않고 상한 아래로 내려갈 때까지 신규 매수를 하지 않는다(ADR-0696과 동일).
- 저장은 기존 변경 이력의 삭제·수정을 거부한다. 화면에서 변경하며 화면·장중 요약에 현재 비중과 변경 이력을 표시한다.

검증: 변경 시각 이전 스냅샷 불변, 이후 매수의 배정액·상한 변화, 기존 주문 불변, 상한 초과 보유 시 미매수, 범위·시간 역순 거부, 같은 값 재변경 무기록.

복구: 변경 기능을 숨기고 마지막 비중을 유지한다. 기록된 변경 이력과 주문은 수정하지 않는다.
