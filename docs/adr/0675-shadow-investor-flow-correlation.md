# ADR-0675: Shadow 기관·외국인 수급과 후속 성과 상관 연구

@responsibility Define dated investor-flow research boundaries.

## Status

Accepted

## Context

사용자가 기관·외국인 수급 현황과 상관성 측정을 요청했다. 기존 KIS 정규화 필드는 수량·금액 별칭 또는 서로 다른 응답 버킷을 합칠 수 있어 연구에 그대로 사용할 수 없다. 수급 누락이나 전략 대기가 기본 관측을 중단해서도 안 된다.

## Decision

- `paperInvestorFlowCollector.ts`는 기존 KIS facade를 통해 직전 KRX 거래일을 명시해 일별 수급을 조회한다. 해당 날짜의 단일 원본 행에 있는 외국인·기관 순매수 **주식 수량**만 인정하고 같은 날짜의 확정 거래량과 연결한다. 금액 별칭, 다른 날짜·종목, 미래 확인 시각, 빈 수량, 0 이하 거래량과 물량 불일치는 제외 사유를 보존한다.
- PAPER 수집의 일별 수급 호출을 추가한다. 성공 응답은 1시간, 미응답은 5분 캐시하며 실제 조회 시각을 유지한다. 거래일이 바뀌면 무효화한다. 기존 기본 KIS 호출 방식, 우선순위·속도 제한과 다른 FULL 소비자는 유지한다.
- `paperInvestorFlowStudy.ts`는 순매수량/동일 일자 거래량을 이용해 외국인·기관·합산 수급과 진입 이후 D1/D3/D5 순수익률의 피어슨·스피어만 상관을 각각 계산한다. 정확한 평가일과 보고 시각까지 확인된 성과만 짝짓고 종목·진입일 중복을 제외한다. 뉴스 방향별, 동반 순매수·순매도·엇갈림·한쪽 이상 0 그룹도 별도 비교한다.
- 최소 3개 유효 쌍부터 기술통계를 표시하며, 이는 전략 채택 기준이나 통계적 유의성 기준이 아니다. 상수 입력과 부족한 표본은 null과 이유로 표시한다. 표본·종목·진입일 수를 함께 제공하며 날짜 내 상관과 겹치는 보유 기간의 의존성을 명시한다.
- 최근 스캔의 종목 간 외국인↔기관 상관·수급 유형 분포는 당일 단면 요약으로 따로 저장한다. 장외에도 현황은 갱신하지만 과거 진입이나 결과 표본을 만들지는 않는다.
- 새 수급 필드는 선택적 계약으로 기본 관측·전략 진입에 고정 저장한다. 과거 진입에 현재 수급을 소급 입력하지 않는다. 화면과 Telegram 분석은 저장한 수급의 기준일·수량·누락 이유를 보여 준다.

## Consequences

후속 수익률 상관은 새 진입의 결과가 쌓인 뒤 계산된다. 기존 기록은 계속 읽을 수 있고 기존 가격 성과는 유지된다. 시작 시 수급 조회가 종목당 한 번 추가되며 이후 캐시를 재사용한다. 상관 수치는 탐색 결과이며 인과관계·예측력·독립 효과의 검증을 의미하지 않는다. 이 변경을 되돌려도 기존 원장과 선택적 필드는 호환된다.

## Guardrails

- Shadow 기본 관측과 뉴스·추세 v2 진입/예약 청산 정책은 유지한다. 수급이나 뉴스 방향을 추가 진입 조건으로 삼지 않는다.
- 새 수급 조회는 기존 KIS 자료 API만 사용한다. 실주문·VTS 주문·계좌·Telegram 실전송 테스트는 실행하지 않는다.
- 수집 실패는 시장 신호가 아니며 null을 0 순매수 또는 0 상관으로 대체하지 않는다.
- Gate·레짐·Kelly를 복구하거나 연구를 자동 매매로 승격하지 않는다.
