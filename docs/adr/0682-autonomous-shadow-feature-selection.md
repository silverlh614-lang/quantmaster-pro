# ADR-0682: Shadow 지표의 자율 연결·해제·재채택

@responsibility shadow — autonomous shadow feature selection

## Status

Accepted

## Context

2026-10-03 사용자는 관측 보고를 넘어 성과가 좋은 지표를 스스로 연결하고 성과가 약해지면 끊는 동적 자율 판단을 요청했다. 기존 v2는 뉴스·20일선 유형과 보유기간만 판단하며 26개 관측 지표는 매매에 연결하지 않았다.

## Decision

- SHADOW의 신규 전략 진입 기본값을 `adaptive-features-v1`으로 바꾼다. 기본 관측을 먼저 저장하고 같은 스냅샷으로 지표 규칙을 선택·적용한다. v1/v2 보유분의 진입 근거·비용·예약 청산은 보존한다. 별도 활성화 승인이나 플래그는 만들지 않는다.
- 동시점에 기록된 26개 수치의 기존 구간과 D1/D3/D5를 개별 규칙으로 비교한다. 각 지표의 구간·기간은 학습 부분에서 선택한다. 재무의 과거 소급 입력이나 과거 종가 재현의 다른 정의 지표를 대신 사용하지 않는다. 뉴스 방향·수급·공시 사건 및 과거 7항목 연구는 이번 자동 선택 범위에 포함하지 않는다.
- 기본 관측의 정확한 D1/D3/D5 가격이 모두 해당 일자 종가 시각 이후, 평가일 00:00 KST보다 이전에 확인된 행만 사용한다. 진입 시 고정 비용으로 재계산하고 종목·진입일 중복을 제거한다. 최근 성숙 진입일 최대 60일을 날짜순 70/30으로 나누며 후반 시작 전에 모든 결과가 확인되지 않은 앞부분 행은 제거한다. 당일 새 결과는 다음 날부터 사용한다.
- 대조군은 해당 지표가 기록된 동일 진입일·시장·뉴스/20일선 유형의 기본 관측이며 선택 표본도 포함한다. 각 날짜에 같은 가중치, 날짜 안에서는 비교 유형에 같은 가중치를 둔다. 단순 누적 승률이나 전체 상승장을 지표의 효과로 취급하지 않는다.
- 학습·후반 각각 10건/3개 진입일, 비용 차감 평균 성과 양수와 대조군 대비 일당 차이 양수를 요구한다. 새 연결의 후반 차이는 0.05%p/일을 넘어야 하고 이미 연결한 규칙은 0보다 큰 동안 유지 후보가 된다. 지표 내 교체와 지표 간 순위에는 0.05%p/일의 유지 여유를 둔다. 학습 구간의 일당 차이 순으로 최대 3개 독립 지표를 사용한다. 이는 탐색 기본값이며 통계적 유의성이나 검증된 수익성을 주장하지 않는다.
- 연결 규칙 중 현재 관측값이 맞는 가장 높은 순위 하나로 종목당 1주 가상 매수한다. 여러 지표 동시 충족·총점·레짐·Kelly·계좌 슬롯은 추가하지 않는다. 현재 지표 누락은 자료 대기로 기록하며 성과 악화로 해석하지 않는다. 모든 규칙이 해제돼도 기본 관측·평가를 유지하므로 추후 성과 회복 시 자동 재채택할 수 있다.
- 매일 첫 스캔에서 전일까지 확인된 자료로 한 번 평가하고 `paper-strategy.json`에 선택 상태를 보존한다. 같은 날·재시작에는 재사용하고 과거 스냅샷의 상태 역행을 거부한다. 연결·교체·해제 이력은 최근 100건으로 제한한다. 매수 때 선택 규칙·정책·학습/후반 표본 수·정렬 ID의 SHA-256 지문·성과 수치·평가 시각을 거래에 고정한다. ADR-0680의 중복 저장 제거를 유지하며 과거 디스크의 전체 ID 목록만 최초 축약 전에 별도 보관한다. 지표 해제는 기존 보유분의 청산일을 변경하지 않는다.
- 화면은 활성 지표·대기/해제 사유·근거·변경 이력과 자율 전략 자체의 사후 청산 성과를 표시한다. 기존 봇의 거래 근거 포맷에도 진입 고정 지표를 표시한다. 새로운 외부 발송이나 스케줄은 만들지 않는다.

## Consequences

추가 관측을 자동으로 매수 판단에 연결한다. 초기 표본 부족이나 후반 성과 악화 때 매수를 기다리는 것은 가능하며 관측은 계속된다. 여러 지표 중 선택하는 과정의 다중 비교, 겹치는 보유기간, 날짜·종목 편중과 선택 편향이 남는다. 학습/후반 보고 성과와 실제 이후 자율 전략 성과는 분리한다. 첫 버전은 고정된 지표 구간을 선택하며 임의의 신규 지표·복합 조건을 생성하지 않는다.

이 결정은 ADR-0678의 26항목 연구 전용 범위와 ADR-0667/0668의 신규 진입 정책을 SHADOW에 한해 확장한다. 그 외 연구를 자동 진입 조건으로 바꾸지 않는 원칙은 유지한다.

## Validation and rollback

자동 연결/매수/해제/재채택, 미래·잘못된 시각·중복·비용 검증, 학습/후반 분리, 동일일 재시작, 원장 저장 실패와 기본 관측 독립, 신구 거래 복원 및 예약 청산, 화면·보고를 검증한다. LIVE/PAPER 주문·provider 호출·SourceSnapshot 수집 정책은 변경하지 않는다.

복구 시 새 진입 dispatch만 v2로 되돌리고 신규 원장 reader와 예약 청산 지원은 유지한다. adaptive 거래를 읽을 수 없는 구버전 전체로 되돌리지 않는다. 과거·현재 원장은 보존한다.
