# ADR-0685: Shadow 기간별 학습과 검증 전 탐색 매수

@responsibility shadow — autonomous learning with prospective exploratory entries

## Status

Accepted

## Context

2026-10-03 운영 자료에는 D1 확정 성과가 7개 진입일에 있었지만, ADR-0682의 D1/D3/D5 동시 완료 조건 때문에 3개 진입일만 학습 후보가 되었다. 이 날짜를 다시 70/30으로 분리하자 D5 확인 시각이 후반 시작일과 겹쳐 학습 표본이 모두 제외되었다. `MISSING_INPUT` 표시도 실제 지표 결측과 기간 분리 후 표본 부족을 구별하지 못했다.

사용자는 실제 주문을 내지 않는 Shadow에서 충분한 측정이 끝날 때까지 진입을 미루는 동작을 거부하고, 검증 전에도 적극적으로 가상 매수하여 연구하도록 요청했다. 검증된 규칙의 채택 기준과 탐색 목적의 진입을 분리한다.

## Decision

- ADR-0682의 모든 기간 동시 완료 조건을 보유기간별 확정 조건으로 바꾼다. 한 기간 이상 유효한 결과가 있는 동시점 관측으로 최근 최대 60개 진입일을 정하고 기존 70/30 날짜 분리를 유지한다.
- D1/D3/D5 규칙은 각각 자기 기간의 정확한 날짜·확정 종가·확인 시각만 사용한다. 평가일 자정 이전 결과만 쓰며, 학습 결과는 후반 시작일 자정 이전에 확인되어야 한다. 다른 기간의 미완료·오류·미래 결과가 유효한 기간을 버리게 하지 않는다. 대조군에도 같은 기간과 시각 조건을 적용한다.
- 검증 매수의 지표 구간과 보유기간은 학습 성과로만 선택한다. 후반 성과를 보고 다른 구간이나 기간으로 재선택하지 않는다. 최소 10건/3진입일, 비용 차감 양수 성과, 대조군 차이, 채택·교체 기준 및 검증 지표 최대 3개 연결은 유지한다.
- 발명 수식도 기간별 학습 결과를 사용한다. 기존 수식·생성 시각·선택 기간·학습 근거는 고정한다. 생성 다음 날짜 이후 진입의 해당 기간 확정 결과로만 검증하며, 연구 종료에 필요한 성숙 날짜도 그 기간을 기준으로 센다.
- 선택 정책에 선택적 `maturityModel: 'per-horizon-v1'`을 기록한다. 이전 표식이 없는 상태는 같은 날짜라도 한 번 재평가하고 이후 일일 고정을 유지한다. 같은 날짜의 기존 탐색 상태가 있으면 보존하여 일일 탐색·생성 상한을 중복 사용하지 않는다. 구 거래의 정책·근거·예약 청산은 변경하지 않는다.
- 선택 상태에 선택적 `horizonSamples` 집계를 기록해 기간별 성숙·학습·검증 건수와 진입일 수를 화면과 보고에 표시한다. 기존 원장은 필드 없이도 읽는다. 새 전체 성숙 건수는 한 기간 이상 확정된 관측 수이며, 기간별 건수를 단순 합산하지 않는다.
- 별도 `shadow-exploration-v1` 경로는 미검증 규칙 최대 2개를 가상 매수에 연결한다. 실제 관측값이 있는 구간에서 후보를 등록하고, 발명 지표를 우선하며 기본 지표·구간·보유기간을 날짜와 순번으로 순환한다. 학습 또는 검증 표본 부족과 발명 후 관측 중인 규칙을 대상으로 하며, 충분히 측정해 우위가 없거나 다른 검증 지표에 밀린 후보를 미검증으로 바꾸지 않는다. 선택한 구간과 기간의 통계를 다시 계산해 기록한다.
- 탐색 등록 관측으로 즉시 매수하지 않는다. 등록 시각보다 늦은 새 가격·지표 관측이 들어오면 장중 실제 가격으로 가상 진입한다. 검증 매수와 여러 탐색 규칙이 동시에 맞으면 종목·날짜 기반 배정으로 각각 진입 기회를 갖는다. 최대 3개/2개는 규칙 수이고 종목 수 상한이 아니다. 종목당 한 보유, 당일 중복 진입 방지, 수량 1, 진입 때 정한 D1/D3/D5 청산은 유지한다.
- 탐색 규칙은 매일 재검토·교체하고, 당일에는 등록 정보가 고정된다. 예전 당일 상태에 탐색 필드가 없으면 첫 유효 관측에서 한 번 초기화한다. 등록 근거는 `explorationEvidence`에 별도로 고정해 보유·청산·재시작 후에도 보존한다. 검증 매수의 `adaptiveEvidence` 조건은 완화하지 않는다.
- 화면·텔레그램에 탐색 가상매수와 검증 전 상태를 명시한다. 전체 자율 전략 성과와 별도로 검증/탐색의 보유·청산·순수익을 전체 원장에서 집계한다. 일부 거래 목록에서 전체 성과를 추정하지 않는다. 독립 기본 관측은 양쪽 경로와 무관하게 계속 쌓이며 연구 선택의 대조 자료로 남는다.

## Consequences

D5 대기가 D1 학습을 막지 않으며, 검증 완료 전에도 탐색 규칙이 새 관측에서 가상 진입한다. 특정 날짜나 종목 수의 매수는 보장하지 않는다. 기간별 확인 가능한 날짜와 탐색 배정이 달라 비교의 선택 편향은 남으며, 검증 통계·검증 매수 실현 성과·탐색 매수 실현 성과를 구별한다. LIVE/PAPER 주문을 만들지 않는다.

## Validation and rollback

부분 성숙, 기간별 미래·중복·잘못된 날짜 배제, 학습 경계와 대조군, 검증으로 재선택 금지, 당일 1회 전환, 발명 이후 검증·종료 및 구 근거 복원을 검증한다. 탐색의 표본 0 진입, 등록 이전·동시·미래 관측 배제, 배정 재현성, 보유·예약 청산 근거, 저장 복원, 목적별 성과와 표시도 검증한다. 운영 원장을 변경하지 않은 사본 비교에서 검증 연결은 0개에서 D1 규칙 3개로 바뀌었다. 복구는 선택·진입 계산을 되돌리되 새 필드 읽기 지원과 기존 진입 근거·예약 청산을 보존한다.
