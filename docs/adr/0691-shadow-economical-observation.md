# ADR-0691: Shadow 절약형 관측

Status: Accepted · 2026-10-04

Railway 사용 비용의 대부분인 CPU·메모리 부담을 줄이되 장중 판단과 정시 보고를 유지한다.

- 자동 전체 스캔은 KRX 거래일 08:00~16:00에 기존 1분 틱을 유지하고 나머지는 30분, 휴장일은 60분 간격으로 실행 필요를 판단한다. 기준은 직전 성공 회차 시작 시각이다. 진행 중 호출은 합친다. 실패는 다음 틱에 재시도하고 명시적 수동 관측은 간격 제한을 우회한다. 08:00부터 정상 주기로 복귀해 08:30 추천 원천을 수집하며 마감 직후 확정 종가 재시도를 유지한다.
- 장중 보유 현재가 30초 감시·뉴스 일정·08:30 발송은 변경하지 않는다. 장외에도 기본 관측과 학습은 주기적으로 계속하며 서버를 절전하거나 중단하지 않는다.
- API에 현재 전체 관측 간격을 표시한다. 화면 및 봇의 지연 판단에 절약형 간격을 반영해 정상 휴장 대기를 장애로 알리지 않는다. 장중 장애 기준은 유지한다.
- 전략 파일의 inode·size·mtimeNs·ctimeNs가 동일하면 이미 검증한 파일의 반복 검증을 생략한다. 저장 시 기존 근거 보존까지 확인한 파일만 재읽기를 생략한다. 새로 저장할 원장은 계속 검증하며 디스크 변경·손상은 재검증한다. 호출별 독립 객체 반환을 유지하고 원장 전체를 추가로 메모리에 캐시하지 않는다.
- 과거 연구는 기존 시간당 확인을 유지하되 입력 파일·지수 자료·한국 날짜가 같으면 재계산하지 않는다. 입력 파일 목록은 연구 수집기와 공유한다. 강제 연구·오류 재시도·새 날짜는 재계산한다. 결과의 원래 asOf를 보존해 실제로 새 연구를 했다고 표시하지 않는다.

검증: 시간 경계/휴일, 자동 스킵과 수동 실행/실패 재시도, 저장 캐시 및 외부 손상 거부, 입력 변화/날짜/강제 연구, 기존 감시·추천·보고·화면 회귀 테스트.

복구: 자동 호출의 scheduled 옵션을 제거하면 기존 매분 실행으로 돌아간다. 검증 지문은 재시작 시 사라지며 원본 파일과 거래 근거를 변경하지 않는다. 실제 비용 절감률은 배포 후 사용량으로 측정한다.

2026-10-05 운영 간격 조정: 사용자 요청에 따라 거래일 08:00~16:00 전체 스캔을 10분, 장중 보유 가격 감시를 1분으로 변경한다. 장전 추천 준비와 마감 종가 정산 구간을 포함하며 나머지 거래일 30분은 유지한다. 휴장일 자동 가격 스캔은 중지하고 수동 실행만 허용한다. API 관측 간격의 null은 휴장 대기를 의미하며, 오래된 관측만으로 장애나 실제 실행 중으로 표시하지 않는다. 분당 스케줄 점검·Telegram 정시 발송·뉴스 수집은 유지한다. 진행 중 전체 스캔은 중복 실행하지 않으며 거래일 실패 재시도는 기존대로다. 보유 가격 미확인은 감시 주기의 2배인 2분을 기준으로 표시한다. 종목별 갱신 완료 간격은 수집량·응답 시간에 따라 달라질 수 있다.

2026-10-06 시간대별 주기(사용자 선택 균형안): 장중 10분이 신규 매수·진입 근거 약화 판단에 길다는 요청에 따라 거래일 08:00~09:00 10분, 09:00~10:00 2분, 10:00~11:30 5분, 11:30~13:30 10분, 13:30~15:20 5분, 15:20~16:00 10분, 그 외 30분으로 나눈다. 08:00~16:00 예약 스캔은 하루 약 48회에서 약 92회로 늘어난다. 한 스캔이 주기보다 길면 연달아 실행되고 겹치지 않는다. 지연 판단의 최소 기준(서버 10분)과 보유 가격 1분 감시는 그대로다.

휴장 연구는 가격·지수 공급자를 호출하지 않는 별도 경로로 분리한다. 같은 저장 자료는 연구 결과를 재사용하며 휴장 날짜 변경·재시작만으로 다시 계산하지 않는다. 시간당 입력 변경을 확인하고 새 자료 또는 명시적 수동 연구에만 재계산한다. 저장 자료 정리와 기존 학습 상태의 AI 연구 요청은 기존 보호 장치를 유지하며 AI의 입력 지문·하루 한도를 지킨다. 새 관측이나 거래를 만들거나 마지막 가격 관측 시각을 갱신하지 않는다. 08:30 휴장 보고는 저장된 원장과 연구 결과를 사용한다.
