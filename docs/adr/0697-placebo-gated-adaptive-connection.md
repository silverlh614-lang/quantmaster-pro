# ADR-0697: 무작위 대조를 통과한 검증 지표만 매수에 연결

@responsibility shadow — validation dates and symbol-permutation chance gate adaptive rule connection

## Status

Accepted

## Context

2026-10-08 연구 점검에서 검증 연결 2개가 후반 확인 3진입일만으로 연결됐다. 종목끼리 수익을 바꾼 무작위 대조(20회)는 같은 수가 우연히 통과할 확률 52%, 규칙별 57%·48%를 보였다. 검증 통과 진입은 평균 −1.97%, 같은 날 미진입 대비 −2.21%p였다. 무작위 대조는 표시 전용이어서 여러 지표를 동시에 검증할 때 생기는 우연 통과를 막지 못했다. 사용자는 권장안(후반 확인 5진입일, 신규 10%·유지 20%, 대조 50회)을 승인했다.

## Decision

- 정책에 `activationModel: 'placebo-gated-v1'`을 둔다. 버전·학습 기준(10건·3진입일)·일당 0.05%p 연결 여유는 바꾸지 않는다.
- 후반 확인(발명 지표는 생성 이후 관측)은 최소 10건·5진입일을 요구한다. 부족하면 기존처럼 `INSUFFICIENT_VALIDATION`·`FORWARD_OBSERVATION`으로 탐색 후보에 남는다.
- 무작위 대조를 하루 1회 50회로 계산하고 순위 결정 전에 적용한다. 규칙별 확률이 10% 이하일 때만 신규 연결하고, 직전 연결 규칙은 20% 이하이면 유지한다. 넘으면 `PLACEBO_NOT_PASSED`(무작위 대조 미통과)로 연결하지 않는다. 구간·보유기간은 계속 학습 구간에서만 고른다.
- 저장 상태 검증은 이 정책의 연결 규칙이 5진입일과 20% 이하 기록을 갖는지 확인한다. 이전 정책 상태·진입 근거는 그대로 읽는다.
- 연결 해제만으로 매도하지 않는다(ADR-0688). 보유 거래·원장·탐색 2규칙·기본 관측·지표 발명은 바꾸지 않는다.

## Consequences

현재 연결 2개는 다음 일일 평가에서 해제될 수 있고, 새 연결은 약 17진입일 누적 이후부터 가능하다. 그동안 매수는 탐색 규칙으로 계속되어 무신호가 아니다. 무작위 대조는 같은 날·같은 시장 안에서만 수익을 바꾸므로 시장 전체 변동을 걸러내지 않는다.

## Validation and rollback

검증 날짜 부족·대조 미통과 신규 차단·연결 규칙 유지 여유·저장 상태 거부와 이전 정책 읽기를 테스트한다. 롤백은 정책 표식과 게이트를 제거하면 되며 저장 원장은 다시 쓰지 않는다.
