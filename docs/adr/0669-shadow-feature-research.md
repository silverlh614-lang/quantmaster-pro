# ADR-0669: 기존 Gate 관측값으로 Shadow 연구 확장

@responsibility Define independent feature research comparisons.

- Date: 2026-09-13
- Status: Accepted

사용자는 기존 Gate 1·2·3의 유용한 조건으로 연구 범위를 넓히되 총점 70점, 조건 일괄 통과, 중복 가감점, 레짐별 제한을 폐기하는 방향을 승인했다.

1. 연구 입력에 저장된 일봉 OHLCV와 KOSPI/KOSDAQ 지수를 추가한다. 기존 종가 원장은 호환하며, 새 기준 실험에도 같은 SourceSnapshot의 확정 일봉 OHLCV와 시장 구분을 보존한다. 별도 공급자 조회는 없다.
2. 비교 항목은 거래량 비율, 시장 대비 20일 상대강도, 5일 모멘텀, 20일 평균가격 이격, 20일 고점 거리, 직전 14일 평균 true range/진입가, 가격 위치의 7개다. 가격 위치는 기존 Gate 3 순수 계산기를 명시적 설정으로 재사용하며 반환 상태를 관측값으로만 사용한다.
3. 진입일 종가 모델의 당일 확정 거래량과 직전 20거래일을 사용한다. 지수는 동일 시장·정확한 날짜·단일 시계열에 한정한다. 미래 봉, 종가만 있는 자료의 가짜 거래량, 수급 건강도로 추정한 순매수, 최신 재무·업종 수치의 과거 소급을 허용하지 않는다.
4. 기존 표본 선택·비용·D1/D3/D5·뉴스 초기 근거는 유지한다. 선택된 시계열의 필드가 부족하면 해당 조건만 미확인 처리한다. 동일 시각의 종가 전용/확장 시계열 중 확장본을 우선하되 서로 다른 가격 묶음은 이어 붙이지 않는다.
5. 각 조건을 독립적으로 연구한다. 숫자 구간은 날짜순 앞선 70% 구간의 중앙값으로 결정하며, 범주/보유기간 선택도 학습 자료에서만 한다. D5 라벨이 후반 시작일에 걸치는 학습 행은 제외한다. 검증 결과에 맞춰 구간·기간을 재선택하지 않는다.
6. 후반 대조군은 같은 조건의 입력이 있는 행 중 동일 진입일·기존 뉴스/20일선 그룹·보유기간으로 맞춘다. 날짜/그룹별 평균을 양쪽에 동일 가중한다. 대조군은 선택 행도 포함하며, 순수한 인과효과나 통계적 유의성을 주장하지 않는다. 표본별 단순 평균도 별도로 제공한다.
7. 7개 가설의 가용/결손, 전체 구간 성과, 선택 근거 수, 후반 종목/날짜 수, 대조군 대비 차이, 비교 불가 상태를 모두 공개한다. 조건 조합·총점·레짐 제한을 추가하지 않으며 연구 결과는 새 진입 필터나 LIVE 정책으로 자동 승격하지 않는다.

검증: 미래 봉 변경 불변, 정확한 지수 날짜 및 시장 분리, 누락/불가능한 OHLC, 비용·기준 표본 유지, 학습/후반 격리, 누락 대조군 분리, 음의 비교 결과 노출, 원본 바이트 보존. 운영 자료 사본으로 계산 후 배포 결과를 확인한다.

복구: 변경 커밋을 revert하고 재배포한다. 원본과 확장 연구 원장은 보존한다. 추가 필드는 이전 종가 연구와 호환된다.
