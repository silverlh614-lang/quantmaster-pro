# ADR-0688: 관측 기반 매도 학습과 동적 조건 확장

@responsibility shadow — prospective exit learning with extensible condition research

## Status

Accepted

## Context

사용자는 기존 26개 밖에서도 필요한 조건을 추가하고 성과가 없는 조건은 덜어내도록 요청했다. 또한 D1·D3·D5를 지키는 것보다 필요한 시점에 매수·매도하는 것이 중요하다고 명시했다. 종전 자율 진입은 지표를 학습했으나 청산은 진입 때 정한 D일의 종가로만 실행했다.

## Decision

- 기본 관측과 D1·D3·D5 평가를 유지한다. 신규 Shadow 거래는 `ADAPTIVE_OBSERVED`로 진입 때 매도 정책과 근거를 고정하고 유효한 새 장중 가격마다 판단한다. D일 도래는 매도 신호가 아니다. 기존 `SCHEDULED_CLOSE` 거래는 원래 예약을 유지하며 소급 전환하지 않는다. 실주문 경로는 바꾸지 않는다.
- 초기 정책은 검증 전 탐색으로 명시한다. 순손실 5%, 순수익 3% 이상 관측 후 고점 대비 1.5%p 반납, 서로 다른 원천에서 진입 조건 3회 불일치 및 20분 이상 지속을 사용한다. 누락·오래된 가격·미래 시각·휴장·같은 시각 재관측은 청산을 만들지 않는다. 기술 지표는 새 완료 거래일, 재무 지표는 새 결산 기간, 현재 PER/PBR은 새 관측 시각으로 반복 원천을 구별한다. 지표 연결 해제만으로 매도하지 않는다.
- 동일 거래에 세 정책(빠른 대응 3/2/1/2회·10분, 기본 대응 5/3/1.5/3회·20분, 여유 대응 7/4/2.5/4회·30분: 손실%/활성수익%/반납%p/신호실패)을 동시에 관측한다. 각 정책의 최초 조건 충족 가격과 비용을 기록한다. 실제 거래가 먼저 청산되어도 D5 비교까지 해당 종목을 계속 수집한다. D5까지 조건이 없던 비교 후보만 확정 D5 종가로 평가하며, 이 비교 결과가 실제 매도 지시가 되지 않는다. 실제 보유가 D5를 넘으면 가격·신호 판단은 계속한다.
- 매도 연구는 모든 후보와 D5 결과가 있는 동일 거래, 중복 없는 종목·진입일, 최대 최근 60진입일만 사용한다. 당일 자정 이전에 확인된 결과를 날짜순 70/30으로 나누고 검증 시작 전에 완료되지 않은 학습 거래를 제거한다. 학습에서 고른 한 후보가 학습·검증 각각 10건·3진입일, 양수 평균 순수익 및 D5 대비 0.1%p 이상 개선을 모두 충족하면 이후 신규 거래에 적용한다. 실패하거나 부족하면 검증 전 기본 탐색으로 돌아간다. 매도 시 원본 관측·실제 발동 근거는 후속 연구와 분리해 동결한다.
- 원지표 6개를 추가한다: 5일 수익률, 20일 일간 수익률 표본표준편차, 고저 범위 내 종가 위치, 20일 종가 위치 가중 거래량 흐름, 5일/20일 상대 일중범위, 10일 순이동/전체이동 효율. 연속된 확정 OHLCV만 사용하고 항목별 자료 부족은 null이다. 과거 26개 기록에는 값을 소급 생성하지 않는다.
- 원지표 등록부에서 조합 탐색 공간을 계산한다. 현재 32개와 평균·차이·곱 3연산의 1,488개 조합을 탐색하며 하루 24개 검토·최대 2개 생성·동시 보관 24개 제한은 계산량을 위한 운영 예산이다. 새 수식은 생성 이후 자료로 검증한다. 26개나 32개를 확장 불가능한 정책 상한으로 취급하지 않으며 외부 자료 수집이나 실행 코드 자체를 임의 생성하지 않는다.
- 성과에 따른 매수 연결·해제·재채택과 검증 3규칙/탐색 2규칙을 유지한다. 모든 조건을 동시에 요구하지 않는다. 발명 후보는 사용 가능한 생성 이후 20진입일, 검증 10건·3일, 명확한 검증 우위 실패, 현재·직전 비활성일 때 연구 종료한다. 순위 밀림이나 자료 부족을 실패로 처리하지 않는다. 과거 진입 근거·변경 이력은 보존한다.
- 화면·CH1 매매·CH2 근거·CH4 연구·평가 API에 관측 매도와 기존 예약 청산을 구별한다. 다른 보유 기간의 실제 매도 성과를 기존 고정 기간 선별력 대조군과 섞지 않는다. 추천 08:30 슬롯은 유지하며 D기간은 성과 비교로 표현한다.

## Validation and rollback

신규 지표 수학·연속 봉·미래 시각·구 26키 복원·동일일 목록 확장, 실패 후보 종료와 미확인 보호를 검증한다. 매도는 D1 이전 손절, 수익 반납, 중복 원천·누락·미래·장외 배제, 실제 청산 후 비교 지속, D5 이후 보유와 신규 청산, 학습/검증 누수·동일 거래 대조·비용·원장 복원·실제 발동 근거 보존을 검사한다. 롤백 시 기존 예약·관측 매도 원장 읽기를 보존하고 새 정책 연결만 중단하며 원장을 과거 정책으로 덮어쓰지 않는다.

## Limits

학습 가능한 매도 기준은 현재 고정한 세 후보 중 선택이다. 임의의 매도 프로그램이나 무제한 지표를 생성하지 않는다. 가격은 수집한 표본이므로 실제 장중 고저·체결 가능 가격·최적 매도점과 같지 않다. 배포만으로 학습 성과가 생기지 않으며 새 후속 관측이 쌓이기 전에는 검증 전 탐색으로 표시한다.
