# ADR-0693: 실제 탐색 거래 기반 자율 배분

Status: Accepted · 2026-10-05

Shadow의 연구 우선순위와 신규 진입에 적용할 탐색 규칙을 실제 가상 거래 결과로 조정한다. 기본 관측, 검증 규칙 선정, 보유 거래의 동결 매도 정책은 기존 경로를 유지한다.

- 원장은 기존 탐색 진입의 정확한 규칙·구간·D 비교 기간·발명 등록 시각으로 묶는다. 가격과 비용으로 청산 순수익을 재계산하며 당일 시작 전 확인된 자료만 사용한다. 구전략·검증 목적 거래·당일/미래 결과·중복 거래를 학습 점수에 섞지 않는다.
- 최근 최대 60개 유효 진입일을 사용한다. 같은 규칙·진입일에 미청산 또는 청산 시각 미확인 거래가 있으면 그 날짜 전체를 등급 계산에서 보류한다. 일부 청산의 평균과 등급용 표본 수는 따로 표시한다. 늦게 끝나는 손실 거래를 빼고 먼저 끝난 수익 거래만 평가하는 편향을 줄인다. 이는 신규 탐색 매수를 막는 조건이 아니다.
- 등급은 완료 날짜별 평균 순수익을 동일 비중으로 계산한다. 10건·3개 진입일 미만이면 탐색 유지(가중치 2), 날짜 평균에서 표준오차 2배를 뺀 값이 양수면 확대(3), 더한 값이 음수면 축소(1), 나머지는 유지(2)다. 이 범위는 수익성 검증·매수 확률·통계적 신뢰 보장이 아니다. 0 가중치로 관측 기회를 끊지 않는다.
- 연구 후보는 기존 자격 범위 안에서 계산한다. 최대 2개 탐색 자리 중 하나는 등급과 표본 수를, 다른 하나는 최근 선택 이력을 우선한다. 두 번째 자리는 현재 같은 종목 집합만 고르는 후보보다 다른 집합을 고르는 후보를 우선한다. 다양한 후보가 없으면 중복만으로 빈 자리를 만들지 않는다. 선택 이력은 규칙별 최근 256개로 제한한다.
- 장중에는 같은 시점 자료에서 조건에 맞는 기존 검증 규칙(가중치 2)과 탐색 규칙(1~3)을 종목·날짜별 재현 가능한 방식으로 배정한다. 가중치가 같으면 기존 균등 배정과 동일하다. 거래 수량은 계속 1주이며 추가 진입 조건이나 실주문 경로를 만들지 않는다.
- 선택 규칙, 같은 후보 안에서의 기존 균등 배정 결과, 후보별 가중치·자료 시점·통계 지문을 진입에 저장하고 보유·청산까지 보존한다. 선택하지 않은 규칙의 가상 체결이나 수익률을 만들어 내지 않는다. 정책 효과는 이후 관측으로 확인한다.
- 일일 연구에서 배분을 고정하고 장중에는 저장된 배분을 사용한다. AI 추가 호출과 공급자 조회는 없다. 계산·검사 실패는 표시·기록하고 기존 순환/균등 배정으로 복귀하며 관측·가상 매매는 계속한다. 구 원장의 선택 기록 부재는 호환한다.

검증: 일자 경계·미완료 날짜·일부 청산 편향·가격 재계산·중복·발명 시각, 작은 표본 유지, 가중 배정 재현/기존 방식 비교, 탐색 다양성/재선택 이력, 재시작·보유·청산의 근거 보존, 오류 복귀, 원장 검증과 화면 설명.

복구: 신규 배분 생성·적용 경로를 기존 방식으로 돌리되 이미 저장한 배분 근거와 거래 정책은 보존한다. 단계별 로컬 커밋만 진행하며 push·Railway 배포는 보류한다.
