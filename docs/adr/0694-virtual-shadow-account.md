# ADR-0694: 독립 신호 검증 위의 가상 계좌 운용

Status: Accepted · 2026-10-07

사용자 요청에 따라 가상 예수금으로 수량을 정해 사고파는 계좌를 구현한다. 기존 1주 Shadow 관측·학습·매도 정책을 보존하고 별도 `paper-virtual-account.json`에 주문과 체결을 기록한다. 로컬 커밋만 하며 push·배포는 별도 요청까지 보류한다.

- 계좌는 전략 화면에서 시작한다. 기본 입력은 1천만 원·종목당 최대 20%·검증 신호만이며 시작 전에 변경할 수 있다. 시작 시각·예수금·비중·탐색 포함 설정은 고정한다. 초기화/원장 교체 API는 제공하지 않는다. 신규 매수 정지·재개는 시간과 함께 기록하고 보유 평가·매도는 계속한다. 엔진 전체 정지는 기존 설정을 따른다.
- 계좌 시작 이후 신규 자율 전략 진입만 대상으로 한다. 동일 스냅샷의 매수 신호를 당시 계좌 현금과 비용 차감 추정 청산 자산의 종목별 비중 상한 안에서 정수 수량으로 배정한다. 같은 시각은 검증→탐색→종목 코드 순으로 처리한다. 이 순서와 비중은 수익 최적화 결과가 아닌 재현 가능한 첫 운용 정책이다. 현금·수량은 기존 1주 신호 학습에 역으로 영향을 주지 않는다.
- 매수는 발생 스냅샷에서만 시도한다. 가격/현금/비중/중복 보유/일시정지/탐색 제외에 걸리면 사유를 기록하고 재시도하지 않는다. 저장 장애로 놓친 과거 매수는 다음 스냅샷에 만료로 기록하고 소급 체결하지 않는다. 계좌 시작 전 보유는 가져오지 않는다.
- 기존 신호 거래의 매도 판단에 따라 계좌 보유 전량을 청산한다. 매도 시 현금 회수를 먼저 처리한 뒤 신규 매수 수량을 계산한다. 가격이 없으면 매도 주문을 대기로 보존하고 다음 유효 가격으로 체결한다. 기존 D5 연구가 끝나도 계좌 보유 종목은 기존 KIS 가격 감시 대상으로 유지한다. 추가 공급자/브로커 실행 경로는 만들지 않는다.
- 체결은 동일 PaperSnapshot의 정상 KIS/KRX 실측 현재가로만 모의한다. 장중·거래일·동일 KST 날짜·2분 이내 가격·미래 시각 금지를 확인한다. 주문의 실제 처리 시각과 가격 관측 시각을 분리한다. 과거 매도 신호가 늦게 처리되면 과거 청산가를 재사용하지 않는다.
- 진입 당시 비용 모델을 고정하고 슬리피지는 체결가, 수수료/매도세는 관측 명목 금액 기준으로 반영한다. 원화 소수 둘째 자리로 금액을 반올림한다. 현금은 체결 증감 합으로, 실현손익은 매수 지출과 매도 순유입으로, 미실현손익은 마지막 관측가의 비용 차감 예상 청산금으로 대사한다. 계좌 수익률은 `(현금+추정 청산금)/초기 예수금-1`이다. 오래된 평가 가격은 잠정 표시하고, 가격 부재는 0으로 만들지 않는다.
- 종목당 상한은 신규 매수 시 적용하며 가격 상승으로 초과했다고 자동 리밸런싱하지 않는다. 추가 매수·부분 매도·종목 교체·호가 잔량 기반 부분 체결·D+2 결제는 이번 버전에 포함하지 않는다. 전량 체결 모의와 매도 대금 즉시 재사용의 한계를 화면에 표시한다.
- 주문 ID는 원본 거래 ID와 매수/매도 방향으로 고정한다. 저장 전 체결 금액·수량·현금을 검증하고 fsync 후 원자 교체한다. 완료 주문 및 초기 설정 변경, 이력 삭제, 손상 원장 덮어쓰기를 거부한다. 계좌 처리 실패는 별도 표시·로그하며 먼저 저장된 신호 거래 및 기본 관측을 취소하지 않는다.
- 실계좌 연결은 미구현이다. 향후 기존 autoTradeEngine 실행 경계에서 주문을 보내고 증권사 잔고·체결로 대사해야 한다. 현재 계좌 코드에는 브로커 주문 함수나 LIVE 전환 경로가 없다. 가상 주문 기록을 실제 체결로 취급하지 않는다.

검증: 비용 포함 정수 수량·현금 보전·동일 신호 재처리·재시작·매도 대기 후 최신가 체결·과거 신호 만료·신규 매수 정지 중 매도·가격 신뢰·손상/저장 실패·독립 관측 보존·API 설정 검증·화면 오류/잠정 평가.

복구: 계좌 처리 호출과 화면 연결을 제거하되 가상 계좌 원장은 보존한다. 기존 신호 원장에는 계좌 수량·현금 정책을 쓰지 않으므로 별도 거래 복원이 필요하지 않다.
