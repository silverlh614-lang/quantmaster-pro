# ADR-0686: Shadow 거래 관측 경로와 청산 복기 기록

@responsibility shadow — durable sampled trade paths for future exit research

## Status

Accepted

## Context

사용자는 종목 추천을 최종 목표로 두고 향후 매도 기능을 확장하되 가상 매수부터 성과와 매도 타점을 기억하도록 요청했다. 기존 전략 원장에는 고정된 진입 근거와 확정 청산 결과가 있지만 보유 중 판단은 매 스캔 교체되어 가격 경로를 복기할 수 없었다.

## Decision

- `paperTradeMeasurements.ts`는 기존 스냅샷으로 진입·장중 보유 관측·예약 종가 확정 시점의 측정을 만든다. 가격 기준 시각, 공급자 관측 시각, 기록 시각을 구별한다. 진입 비용을 고정해 순수익률·손익을 계산하고 당시 행동·사유와 진입 규칙의 현재 값·일치 여부·연결 여부를 보존한다. 지표 결측은 null이며 현재 지표를 과거 청산 시각에 붙이지 않는다.
- 원장에는 거래별 추적 시작·진입부터 추적했는지·측정 수·최근/관측 최고/관측 최저 요약만 추가한다. `paperTradeMeasurementValidation.ts`가 시각, 고정 비용, 진입·청산 원본과의 일치를 검사한다. 기존 필드 없는 거래도 읽는다. 기존 보유분은 첫 유효 관측부터 부분 추적하고 이미 끝난 거래의 과거 경로는 만들지 않는다.
- 보유 가격은 거래일 정규장 중 유효한 새 관측만 기록한다. 미래·역행·중복 시각, 가격 오류, 예약 청산 이후 가격은 제외한다. 청산 종가가 늦게 확인되면 실제 가격 기준 시각과 확인 시각을 따로 남긴다. 표본 최고·최저는 시장의 정확한 장중 고저점이나 당시 알 수 있었던 최적 매도점이 아니다.
- `paperTradeMeasurementRepo.ts`는 거래 ID·진입 스냅샷 ID로 연결한 상세 행을 `paper-trade-observations/날짜/스냅샷해시.json.gz`에 스캔별 불변 묶음으로 저장한다. 동일 재시도는 허용하고 다른 내용의 덮어쓰기는 거부한다. 상세 경로를 매번 전체 원장에 복제하지 않는다.
- 기본 관측과 전략 원장을 먼저 저장하고 상세 경로를 저장한다. 측정 계산·검증 실패는 기존 요약으로 되돌리고 거래 처리를 계속한다. 상세 저장 실패도 이미 확정한 가상 매수·청산을 취소하지 않는다. 별도 상태 파일로 실패 횟수·미확인 측정 수를 보존하고, 원장 저장 직후 중단된 경우도 전체 원장의 측정 수로 감지한다. 저장 확인이 불가능한 구간은 보수적으로 미확인 상태로 남기며 조회 실패를 0건으로 표시하지 않는다.
- 대시보드 거래 카드와 텔레그램 CH2 청산 복기에 관측 경로·부분 추적 여부·관측 최고 순수익과 확정 청산 순수익의 차이(%p)를 표시한다. 상세 저장 문제는 거래 오류와 구별한다. 최종 추천 순위나 동적 매도 정책, 청산 후 가격 강제 수집은 이번 결정에 포함하지 않는다.

## Consequences

새 가상 거래의 보유 경로가 재시작 후에도 이어져 향후 매도 조건 연구의 근거가 된다. 정규 관측 간격 사이의 고저점과 과거 미기록 구간은 알 수 없다. 예약 D1/D3/D5 청산, 독립 기본 관측, 지표 선택·탐색 정책, 공급자·실주문 경계는 유지한다. 상세 파일은 연구 원본으로 보존하며 별도 전 구간 조회 화면은 아직 제공하지 않는다.

## Validation and rollback

부분 추적·중복·시각 역행·지연 종가·고정 비용·진입 규칙 보존, 원장 복원, 압축 기록 불변성, 실패 후 재시작·누락 감지, 거래 저장과 상세 저장의 장애 격리 및 화면·CH2 표시를 검증한다. 복구 시 측정 호출과 표시를 되돌리되 새 선택 필드를 읽는 호환성과 이미 저장한 원본 기록을 보존한다.
