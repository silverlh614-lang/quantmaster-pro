# ADR-0684: Shadow 채널의 장중 판단과 자율 연구 보고

@responsibility telegram — autonomous research reporting

## Status

Accepted

## Context

2026-10-03 사용자는 텔레그램 채널에 담을 내용을 더 활성화하도록 요청했다. 기존 진입·청산, 아침 뉴스, 마감·주간 보고에 ADR-0682/0683의 자율 연구 과정과 장중 판단이 충분히 드러나지 않았다.

## Decision

- 기존 매분 `paper_bot` 작업과 채널 라우터를 사용한다. CH1(TRADE)은 가상 진입·청산, CH2(ANALYSIS)는 진입 근거·청산 복기와 거래일 10:30/13:30 장중 판단, CH3(INFO)는 08:45 해외 뉴스·국내 연관주, CH4(SYSTEM)는 연구 변경과 16:10 마감·일요일 19:00 연구를 담당한다. 운영 상태는 개인 DM으로 유지한다.
- 장중 보고는 45분 안에서 각 시각별 하루 한 번 보낸다. 같은 스냅샷의 기본 관측과 전략 판단이 모두 최근 10분 내 기록이고, 장중 관측이며 자동 관측이 일시정지되지 않았을 때 사용한다. 로딩·오류·미래 자료는 슬롯을 소모하지 않고 다음 점검을 기다린다. 전송 실패 후 재시도할 때도 신선도·일시정지를 다시 확인하고 같은 슬롯 ID의 본문을 최신 판단으로 갱신한다. 발송 조건이며 관측·매수 조건을 추가하지 않는다.
- 지표 생성·매수 연결·해제·교체·연구 종료는 최근 24시간의 실제 변경 이력으로 알린다. 변경 시각·지표·이전/이후 규칙·사유로 고정 ID를 만들고 최대 3건씩 묶는다. 새 `researchInitializedAt`으로 기존 봇 업그레이드 시 과거 이력을 별도로 등록하며 첫 점검에 재방송하지 않는다. 최초 정상 전략 조회 이후 새로 발생한 연구는 발송한다.
- 알림 원장에 `intraday`, `research` 종류를 추가하고 기존 schemaVersion 1과 목적지 없는 DM 기록을 읽는다. 새 연구 메시지는 6시간, 장중 메시지는 해당 슬롯 종료까지 재시도한다. 기존 메시지 ID 확인·최대 6회 재시도·채널별 독립 상태를 재사용한다. 미전송 상태를 성공으로 바꾸지 않는다.
- `/paper`, 마감·주간 연구에는 탐색 회차, 검토·보관·생성 후 검증·채택 수와 자율 전략만의 확정 성과를 포함한다. 과거 7조건 재현 연구, 후보 학습·검증 성과, 실제 가상 거래 성과를 구분한다. 저장 자료 연구가 없어도 자율 연구 상태를 보고할 수 있다. 과거 변경 시점의 성과를 현재 후보 성과로 대체하지 않는다.

## Consequences

신규 매매가 없는 날에도 최근 판단의 대기 사유와 자율 연구 진행이 채널에 나타난다. 같은 내용의 매분 방송 대신 정해진 장중 보고와 실제 연구 변화만 추가한다. 메시지는 HTML을 이스케이프하고 Telegram 한도 안에서 정리한다. 채널이 비활성이거나 목적지가 없으면 기존대로 재시도·실패로 남는다.

## Validation and rollback

KST 두 슬롯·휴장·오류·지연·일시정지·스냅샷 불일치, 최초 연구 등록·재시작 중복·재시도·구 원장 호환, 실제 채널 라우터 연결, HTML·분량·미집계·미래 성과를 테스트한다. 테스트 발송은 모의 전송으로 검증한다. 복구는 새 스케줄과 연구 enqueue를 제거하되 새 원장 종류의 reader와 이미 기록한 발송 상태는 유지한다. 거래 원장·공급자 수집·Shadow 채택·실주문 정책은 바꾸지 않는다.
