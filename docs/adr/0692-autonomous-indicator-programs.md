# ADR-0692: 자율 계산 프로그램 연구

Status: Accepted · 2026-10-05

기존 관측 자료로 AI가 계산 절차를 제안하고 발명·탐색·검증 경로에 등록한다. 기존 32개 재료와 단순 조합 연구를 보존한다.

- 1단계는 허용 연산으로 구성한 JSON 계산 트리다. 여러 재료의 사칙연산·평균·절댓값·부호 반전·최소/최대·조건 분기를 지원한다. 원시 JavaScript/Python 실행, 파일·네트워크·주문 접근, 새 외부 출처 연결은 포함하지 않는다. 입력은 해당 시각의 저장된 관측 지표이며 임의 과거값·미래 성과 필드는 허용하지 않는다.
- 트리는 최대 31노드·6단계·6개 재료다. 고정 환산값을 사용하고 중간 연산은 ±27, 최종값은 ±3으로 제한한다. 입력 누락과 0에 가까운 나눗셈은 미확인이다. 모든 분기의 입력이 있어야 계산한다. 코드 식별자는 버전·정규 계산 절차의 SHA-256이며 이름 변경으로 연구 이력을 초기화할 수 없다.
- AI 제안은 기존 Gemini 경로와 예산 관리를 이용한다. 장외 전체 스캔 뒤 비동기로 새 확정 자료가 있을 때 한국 날짜당 한 회차, 최대 2개를 제안한다. 시도 시각·입력 지문을 먼저 저장하여 재시작/중복 호출을 억제한다. 공급자 내부 통신 재시도는 기존 정책을 따른다. 장중에는 AI 생성 없이 등록된 계산만 수행한다.
- AI에는 지표 정의와 집계된 학습 결과를 제공한다. 해당 회차의 후반 검증 결과·추천 원문·개별 거래·인증정보를 제공하지 않는다. AI 설명은 가설로 표시하고 실제 연산·표본 성과와 구분한다.
- 후보 계산 검사를 통과해도 바로 검증 매수로 승격하지 않는다. 기존 학습 구간에서 구간/측정 기간을 선택하고 동일 표본만 고르는 원지표의 복제를 제외한다. 등록 이후 새 관측으로 탐색 가상매수·검증·해제·연구 종료를 수행한다. 기존 검증 3개/탐색 2개 한도와 매도 기준, 일일 규칙 동결을 유지한다.
- 후보 큐와 핵심 거래 원장을 분리한다. AI 실패·후보 파일 손상은 연구 상태에 표시하고 기본 관측·기존 매매를 차단하지 않는다. 후보는 최대 12개 보관하며 등록된 식과 거래별 근거는 기존 원장에 고정한다. 날짜·가설·계산 절차·버전·연구 상태를 대시보드에서 설명한다.

검증: 잘못된 연산/과도한 트리/입력 누락/0 나눗셈, 지문 변조·구 수식 호환, 생성 이후 시간 경계·탐색/정식 진입·동결 매도, 재시작·중복·AI 오류·원장 손상 격리, 대시보드 설명 및 Telegram 출력.

복구: 신규 AI 후보 생성·등록 호출을 분리해 중지할 수 있다. 이미 생성된 프로그램의 해석기와 저장된 거래 근거는 유지해야 하며, 프로그램 거래가 생긴 뒤 해석기 제거로 되돌리지 않는다. 이 변경은 실주문 연결 승인이 아니다. 사용자 지시에 따라 단계별 로컬 커밋만 하고 푸시·Railway 배포는 별도 진행한다.
