# ADR-0677: Shadow 마감 요약과 장중 판단 사유 보존

@responsibility Preserve closing-report evidence across after-hours observation scans.

## Status

Accepted

## Context

- 기존 마감 보고는 누적 성과 위주여서 당일 평가 성과와 과거 평가일의 지연 수집을 구분하기 어려웠다. 장후 스캔이 최신 대기 사유를 `MARKET_CLOSED`로 교체해 장중 미진입 이유도 사라졌다.
- 사용자 요청은 마감 요약 개선이다. 매매 자격·비용·청산 정책이나 새 매수 조건을 변경하지 않는다.

## Decision

- 전략 원장에 선택 필드 `lastMarketSession`을 추가한다. 같은 SourceSnapshot에서 만들어진 장중 마지막 판단의 날짜·시각·스냅샷 ID·사유별 건수만 보존한다. 장후·주말 스캔은 이를 덮어쓰지 않고 다음 유효한 장중 스캔에서 갱신한다. 전체 판단 이력을 복제하지 않는다.
- 순수 `paperCloseReport.ts`는 전체 기본 관측·전략 읽기 뷰로 오늘 신규, 오늘 평가일 D1/D3/D5, 누적 성과, 지연 확인, 미확정 결과와 다음 평가일을 집계한다. 달력과 확정 시각을 검증하고 미래 자료를 제외한다. 전략 진입·예약일 청산은 기본 관측 성과와 분리한다.
- 뉴스·공시·수급은 기존 관측 결과를 사용한다. 공시 수집 범위·연결 누락, 제목 기준 호악재, 직접 원문, 수급 기준일과 확인 범위를 표시한다. 비상장 자료가 섞인 일반 알림 제목 목록으로 마감 보고를 채우지 않는다.
- 기존 16:10 CH4 마감 슬롯·메시지 ID·중복 방지·재시도 정책은 보존한다. 한 메시지 예산 3,500자 안에서 선택적 원문 예시를 추가한다. `GET /api/shadow/close-report`는 같은 문안을 전체 원장으로 미리보기만 하며 수집·Telegram 발송을 실행하지 않는다.

## Consequences

- 도입 전 장중 사유는 미기록으로 표시한다. 장후 대기로부터 표본 부족이나 기대성과를 추정하지 않으며, 이미 보낸 메시지를 변경하거나 다시 발송하지 않는다.
- 마감 전·갱신 지연·일부 원장·자료 누락을 명시한다. 수집 기준 시각과 경제적 평가일을 분리하여 과거 결과가 오늘 성과로 섞이지 않게 한다.

## Guardrails

- 주문·공급자 조회·매수·청산 계산 경로를 추가하지 않는다. 이전 원장은 새 필드 없이 읽을 수 있다.
- 장후 재시작 시 사유 보존, 거래일·가용 시각 검증, 0%와 미확정 구분, 지연 청산, HTML 이스케이프·길이, 미리보기의 읽기 전용 성격, 기존 메시지 중복 방지를 검증한다.
