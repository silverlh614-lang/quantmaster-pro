# ADR-0683: Shadow 지표 수식의 생성과 지속 연구

@responsibility shadow — autonomous indicator discovery

## Status

Accepted

## Context

2026-10-03 사용자는 기존 지표의 선택에 더해 독자적인 지표를 만들고 계속 자동 연구하는 로직을 요청했다. ADR-0682의 기본 관측·자율 채택 경로를 확장한다.

## Decision

- `indicator-discovery-v1` 연구 상태를 기존 `adaptive-features-v1` 원장에 선택 필드로 추가한다. 기존 26개 수치 중 서로 다른 두 항목의 평균·차이·곱 수식을 자동 생성한다. 피연산자는 각 원지표의 기존 구간 중심·폭으로 정규화하고 [-3,3]으로 제한한다. 수식·정규화 상수·생성 시각·구간·D1/D3/D5·학습 근거를 고정한다. 코드 생성·eval·외부 AI 호출·재귀 수식은 사용하지 않는다.
- 고정 연산 문법은 회차당 975개 조합이다. 매일 기존의 정화된 학습 부분에서 최대 24개를 평가하고 비용 차감·대조군 대비 우위가 있는 최대 2개를 연구 후보로 보관한다. 자료가 부족한 조합은 시도 완료로 처리하지 않는다. 입력이 상수이거나 선택 표본이 원지표 구간과 같은 수식은 새 지표로 채택하지 않는다. 구간 [-1,0,1]과 보유기간은 학습에서만 선택한다.
- 생성 이전의 후반 성과로 신규 수식을 활성화하지 않는다. **생성일 다음 날부터 진입한 기본 관측** 중 모든 D1/D3/D5 결과가 평가일 00:00 KST 전에 확인된 행만 생성 후 검증에 쓴다. 당일 새 결과·소급 생성·현재값의 과거 대입은 제외한다. 최근 성숙 진입일 60일 창에서 날짜/시장/뉴스·추세 비교와 ADR-0682의 10건/3일·양수 순수익·일당 초과성과 기준을 적용한다.
- 기존 지표와 발명 지표는 동일한 최대 3개 활성 규칙 자리를 비교한다. 하나의 규칙이 맞으면 종목당 1주 Shadow 매수한다. 여러 규칙의 동시 충족이나 총점으로 바꾸지 않는다. 입력 누락은 대기이며 기본 관측은 계속된다. 생성 후 성과가 약해지면 해제하고 회복하면 재채택한다.
- 보관은 최대 24개다. 생성 후 사용할 수 있는 성숙 진입일이 20일 이상 쌓인 비활성 후보는 새 연구 공간이 필요할 때 종료할 수 있다. 현재 사용할 수 있는 조합을 모두 검토한 뒤 연구 회차 시작 이후 새로운 학습 진입일이 20일 이상 누적되면 다음 회차를 시작한다. 새 회차에서는 보관 수가 적어도 이전 회차의 실패한 후보를 하루 최대 2개 회수해 재연구한다. 관측일이 부족한 후보, 당일 또는 직전 평가에서 활성인 후보는 보존하고, 순위에서만 밀린 유효 후보는 공간이 충분하면 유지한다. 직전 활성 보호로 회수가 미뤄진 실패 후보는 같은 연구 회차의 다음 평가에서도 회수할 수 있다. 유지 후보는 수식을 변경하지 않는다. 재생성한 후보는 새 생성 시점부터 다시 검증하므로 과거 검증을 재사용하지 않는다.
- 같은 날짜의 첫 평가를 저장해 재시작 때 재사용한다. 수식·학습/검증 표본 수·ID 지문은 거래 진입 근거에도 고정하고, 상태에서 연구 종료돼도 예약 청산과 당시 근거를 유지한다. 저장 시 발견 상태·규칙·변경 이력의 중첩 학습 ID도 기존처럼 지문으로 축약한다. 신규 provider·주문·봇 스케줄을 추가하지 않는다.
- 화면은 탐색 회차와 검토/보관/관측/채택 수, 생성된 수식, 생성 시각, 생성 이후 성과와 연결·해제·연구 종료 이력을 보여 준다. 기존 기본 지표 원장도 읽을 수 있다.

## Consequences

기존 수치로부터 새로운 합성 지표를 만들고 새 데이터로 계속 연구한다. 발명 범위는 명시한 수식 문법 안이며 임의의 새로운 원자료나 무제한 지표 발명은 아니다. 제한된 순차 검증은 다중 비교·반복 선택의 편향을 완전히 제거하지 않으며 통계적 유의성·수익성을 보장하지 않는다. 학습 성과와 생성 후 검증, 실제 Shadow 거래 성과를 구분한다. LIVE/PAPER 승격은 없다.

## Validation and rollback

수식의 결정성·결측·변조 거부, 과거 결과를 통한 즉시 채택 금지, 생성 후 채택/해제, 일일 재시작·새 연구 회차, 저장 축약·손상 거부, 진입 고정 및 예약 청산, 화면과 기존 기준 관측을 테스트한다. 복구 시 후보 생성과 발명 지표의 신규 진입만 중단하고 새 원장 reader·기존 거래의 청산 지원을 유지한다.
