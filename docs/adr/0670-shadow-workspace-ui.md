# ADR-0670: Shadow 워크스페이스와 가벼운 화면 조회

@responsibility Define the research workspace boundary.

- Date: 2026-09-13
- Status: Accepted

사용자는 사용하지 않는 대시보드 기능의 전면 정리와 웹 UI 경량화를 요청했다.

1. 기본 화면과 탐색을 운영 현황·기본 관측·전략 판단·저장 자료 연구·운영 설정으로 통일한다. 예전 브라우저 이력은 새 화면으로 연결한다. Gate·레짐·Kelly·총점·공개 리포트·후보 발굴 화면과 전역 자동 조회·모달·클라이언트 원장 동기화를 초기 앱에서 분리한다. 서버 관심 목록과 거래·학습 원장은 변경하지 않는다.
2. `/api/shadow/experiments?section=overview`는 기존 원장에서 요약만 투영한다. 관측·전략·연구도 해당 section으로 필요한 자료만 조회한다. section 없는 기존 API는 호환한다. 통계·정책·주문·공급자 호출 경계는 동일하다.
3. 초기 화면은 요약·모드·일시정지 상태만 30초 간격으로 조회한다. 상세 코드와 자료는 해당 화면에서만 불러온다. 연구 조회는 60초 간격이며 숨겨진 탭의 폴링은 중단하고 복귀 때 재확인한다. 대용량 조회 결과의 localStorage 복원·매번 직렬화는 중단하고 메모리 캐시를 사용한다. 원본 영속화는 기존 서버 원장이 담당한다.
4. 긴 판단·관측·거래 목록은 검색·상태 필터·페이지로 나눠 표시한다. 미확인·오류·미완료·0%를 구분하고 기본 관측, 선택 전략, 과거 재현의 수익률을 합산하지 않는다. 연구 비교는 모든 조건의 후반 대조군 대비 %p와 표본 범위를 표시하며 자동 정책 승격은 없다.
5. 실행 모드는 서버 값만 표시한다. 모드 확인 실패나 다른 모드에서는 화면의 수동 Shadow 스캔을 비활성화한다. 다른 서버 모드의 실행 관리는 명시적으로 열 때 기존 관리 화면을 불러오며 기존 실주문 안전장치를 사용한다.

검증: 신규 진입 시 세 개 조회, 미사용 페이지 조회·쓰기 없음, 이력 복구, 오류/미완료/0% 분리, 요약 투영 원본 불변, 목록 필터, 데스크톱·모바일 탐색 테스트, 격리된 변경 전후 빌드 비교, lint·validate:all·실제 커밋 훅. 현재 세션에 연결된 브라우저가 없어 실제 화면의 시각 검수는 수행하지 못했다.

복구: 이번 커밋을 revert하여 재배포한다. 서버 원장과 개인 화면 설정은 보존된다.
