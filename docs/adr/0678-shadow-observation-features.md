# ADR-0678: Shadow 동시 조건 관측과 독립 재무 보강

@responsibility Preserve contemporaneous technical and financial research without adding entry gates.

## Status

Accepted

## Decision

- 사용자 요청에 따라 같은 관측에 기술·실적·재무 26개 수치를 고정한다. RSI/Wilder ATR/ADX, MACD, 볼린저, 스토캐스틱, 이동평균·수익률·거래량은 동일 SourceSnapshot의 완료 일봉을 재사용한다. 누락 거래일을 건너뛰지 않으며 현재가 PER/PBR와 완료일 지표의 기준을 구분한다.
- 동일시장 관측군 20개 이상일 때 20일 수익률 중앙값 대비 차이를 기록한다. 거래소 지수 대비 수익률이나 업종 상대강도로 표현하지 않는다.
- 재무는 기존 KIS 재무 클라이언트와 DART 재무 수집 함수를 재사용한다. 가격 수집은 기다리지 않는다. 스캔 시작 시 캐시 사본을 SourceSnapshot에 고정하고 배경 갱신 결과는 다음 스냅샷부터 사용한다. 한 작업 최대 8종목, 순차 처리, 60초 이후 새 종목 시작 중단, 중복 작업 금지. 성공 24시간·실패 1시간 재시도, 48시간 초과 캐시는 연구 값에서 제외한다. 기존 공급자 제한·타임아웃을 유지한다.
- `paper-financials.json`은 원장과 독립적으로 원자 저장한다. 손상된 파일을 덮어쓰지 않으며 기본 관측을 중단하지 않는다. KIS 비율·손익·안정성 결산기간을 구분하고 DART 연결/별도·기간·확인 시각을 보존한다. 서로 다른 공급자·기간의 금액으로 비율을 만들지 않는다. 적자 연구는 현재 영업/순이익률, 영업현금흐름 부호, 자본/자산 비율이다. 연속 적자·흑자 전환·자본금 대비 잠식 여부를 추정하지 않는다.
- 새 필드는 선택 필드로 추가하고 과거 진입 관측을 소급 보충하지 않는다. 각 지표 구간별 D1/D3/D5 순수익·승률·종목 수·진입일 수를 표시한다. 다중 비교와 날짜 집중의 한계를 명시하며 추천 순위·매수 자격·실주문에 사용하지 않는다.
- 기본 관측 화면에 현재 수집률·개별 종목 당시 값·구간별 성과를 제공하고 기존 마감 보고에 핵심 확보 수를 추가한다. 새 Telegram 발송 슬롯은 만들지 않는다.

## Validation and rollback

- 운영 검증 중 기존 KIS 매핑의 `op_prfi`는 경상이익임을 확인했다. 영업이익은 `bsop_prti`로 수집하고 이전 재무 캐시의 영업이익률은 재확인 전까지 사용하지 않는다. 근거: [KIS 공식 손익계산서 필드 정의](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/domestic_stock/finance_income_statement/chk_finance_income_statement.py).

- 계산 기준값, 미래/미완료/누락/중복 일봉, 재무 시각·기간, 캐시 손상·재시도·배경 작업 상한, 원장 복사·과거 기록 호환, 화면·수집·보고 경로를 검증한다.
- 되돌릴 때 신규 관측 연결만 제거한다. 추가 필드는 이전 코드에서 무시되며 기존 관측·전략·주문 원장은 보존한다.

운영 검증에서 60일 이동평균 전건 결측 원인이 2026-07-17 제헌절 휴장 누락임을 확인했다. KRX 휴장일 SSOT에 해당 날짜를 반영한다([KRX 공지](https://strn.krx.co.kr/corebbs5/BHPSTRN0401/list)). 실제 거래일 결측 시 계산 중단은 유지한다.
