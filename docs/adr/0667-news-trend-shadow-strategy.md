# ADR-0667: 뉴스·추세 성과를 Shadow 진입과 예약 청산에 연결

@responsibility Define empirical news-and-trend Shadow decisions without changing baseline sampling or broker execution.

- Date: 2026-09-12
- Status: Accepted

## Context

ADR-0666의 `shadow-baseline-v1`은 후보마다 1주씩 진입해 뉴스·추세별 D1·D3·D5 성과를 관찰한다. 사용자는 그 성과를 실제 진입·청산 조건으로 바꾸는 후속 작업을 요청했다. 이번 범위는 SHADOW 안에서 조건부 가상 매수와 예약 가상 청산을 실행하는 것이다. LIVE/PAPER 브로커 경로와 자동 승격은 변경하지 않는다.

기준 실험 자체를 조건부로 바꾸면 탈락한 후보의 결과가 사라진다. 현재 비교표는 뉴스 유무와 추세를 각각 집계하고, 전체 뉴스 보관분도 포함하므로 이를 그대로 매수 조건으로 쓸 수 없다. 학습 시각 이후에 확정된 결과를 사용하거나 조건 선택에 쓴 과거 수익률을 새 거래 성과로 표시해서도 안 된다.

## Decision

1. 기준 실험과 조건부 전략을 함께 실행한다. `shadow-baseline-v1`의 후보별·거래일별 1주 표본 수집과 D1·D3·D5 평가를 유지한다. 신규 `news-trend-v1`만 뉴스·추세 성과에 따라 BUY/WAIT/HOLD/EXIT를 결정한다. 레짐, Kelly, Gate 점수, 승인 큐, 계좌 슬롯, 섹터 한도, 전역 학습 가중치를 입력에 추가하지 않는다.
2. 같은 `PaperSnapshot`에서 기준 실험과 전략을 결정한다. 전략의 보유 종목을 기존 관측 대상에 합치며 기존 collector의 단일 수집을 재사용한다. 전략 policy 내부는 provider를 호출하지 않는다.
3. 진입 시점에 관측한 최근 72시간 뉴스 유무와 20일선 위/이하를 교차해 4개 그룹을 만든다. 뉴스 시각은 해당 관측의 `observedAt`이며 미래 뉴스는 제외한다. 과거 기준 실험도 각자의 진입 시각을 기준으로 동일하게 분류한다. 20일선 정보가 없으면 전략은 `TREND_UNKNOWN`으로 대기하고 기준 실험은 계속 수집한다. 뉴스의 존재를 호재·악재나 AI 감성으로 해석하지 않는다.
4. 학습 입력은 `shadow-baseline-v1`의 성숙한 기준 실험만 사용한다. 한 실험의 D1·D3·D5 세 결과가 모두 정확한 예정 거래일에 해당하고, 그 종가의 사용 가능 시각이 해당 거래일 종가 시각 이후이며 현재 결정 시각보다 엄격히 이전이어야 한다. 미래 진입·잘못된 시각·비정상 결과는 제외한다. 종목/진입 거래일 중복도 제거한다. 세 보유 기간은 반드시 같은 표본으로 비교한다. 현재 스냅샷에서 처음 확인된 결과는 같은 스냅샷의 신규 매수 근거로 즉시 사용할 수 없다.
5. 같은 그룹에 최소 10개 실험, 서로 다른 진입일 최소 3개가 있어야 조건부 진입을 판단한다. 이는 초기 탐색을 위한 공개된 정책 기본값이며 통계적 유의성이나 검증된 수익성을 뜻하지 않는다. D1·D3·D5별 평균 비용 차감 수익률을 보유 거래일 수로 나눈 값이 가장 높은 기간을 선택하고 동률이면 짧은 기간을 우선한다. 선택한 평균 수익률이 양수일 때만 유효한 장중 현재가로 1주 가상 매수한다. 표본 부족·진입일 부족·비양수 성과·가격 결손·장외·중복 진입 사유는 각각 기록한다.
6. 진입할 때 정책 버전·기본값, 그룹, 학습 cutoff, 근거 실험 ID, 표본 수/진입일 수, 모든 기간의 평균·승률, 선택한 기간, 진입 관측, snapshot ID, 비용 모델을 고정한다. 거래당 예약 청산일과 시각도 이때 고정한다. 이후 새로 학습한 기간으로 기존 보유 거래의 청산일을 옮기지 않는다. 한 종목에는 열린 전략 거래 하나만 두고 종목/거래일별 전략 진입도 한 번으로 제한한다. 이는 중복·보유 상태 관리이며 기준 실험이나 다른 종목의 수집을 막는 슬롯 정책이 아니다.
7. 청산 모델은 `SCHEDULED_CLOSE`이다. 진입 시 선택한 D1/D3/D5의 정확한 거래일 종가로 가상 예약 청산한다. `effectiveAt`은 미리 정한 거래일의 15:30 KST, `observedAt`은 그 종가가 실제로 관측 가능해진 시각, `decisionAt`은 결과를 반영한 스냅샷 시각으로 따로 기록한다. 이는 사전에 정한 종가 주문의 시뮬레이션이며 사후 현재가 체결로 표시하지 않는다. 해당 종가가 없거나 아직 미래이면 HOLD로 기다리고 다음 날 종가로 대체하지 않는다. 조건·기간을 사후 선택하여 과거 청산을 만드는 것은 금지한다.
8. 전략 거래는 자신의 진입가·예약 청산가·진입 시 고정 비용으로 손익을 계산한다. 근거로 사용한 과거 실험 수익률을 전략 거래 성과로 복사하지 않는다. 조건부 전략의 완료 거래 수·평균 순수익률·승률·1주 손익 합계는 기준 실험 성과와 분리하며 계좌 수익률로 표시하지 않는다. 전체 전략 거래를 집계한 뒤 화면용 최근 200건을 자른다.
9. 별도 `paper-strategy.json` 원장에 전략 거래, 최신 스캔의 종목별 판단과 최근 실행 요약을 보관한다. 기준 실험 원장의 schema를 바꾸거나 과거 기록을 재해석하지 않는다. 기준 실험을 먼저 저장하고 전략 처리를 진행한다. 전략 원장 읽기·평가·저장 장애는 오류로 노출하고 기준 실험 저장을 취소하거나 중단하지 않는다. 손상 원장을 빈 값으로 덮어쓰지 않는다. 반복 실행과 재시작에서도 진입과 청산은 멱등적으로 처리한다. 매분 판단 이력을 무한 추가하지 않고 진입·청산 판단은 각 거래에 고정 보관한다.
10. 기존 스캔 결과와 읽기 모델에 선택적 `strategy` 필드를 추가하고 실제 Shadow 화면에서 진입·대기·보유·청산 사유와 근거를 보여준다. 신규 활성화 flag는 추가하지 않는다. 기존 SHADOW dispatcher에서 기본 실행하며 롤백은 이 변경 커밋의 revert다. 이미 저장한 원장은 롤백 시 삭제하지 않는다.

## Patch Scope Guard

- `targetDomain`: Shadow 실험/전략, 공유 계약, Shadow 대시보드.
- `allowedFiles`: `server/trading/paper/*`, `server/persistence/paperStrategyRepo*`, `src/types/paperExperiment.ts`, `src/types/paperStrategy.ts`, `src/components/autoTrading/Paper*`, 관련 회귀 테스트, 본 ADR/INDEX, ARCHITECTURE, 변경 이력 및 하네스 기록.
- `forbiddenFiles`: LIVE/PAPER 주문 본체, Gate/레짐/Kelly 정책, KIS client, SourceSnapshot 생성 정책, 기존 거래 원장 및 전역 학습 writer.
- `expectedBehaviorChange`: 동일 스냅샷에서 무조건 기준 실험과 성과 기반 조건부 전략을 함께 실행하고 예약 종가 청산과 명시적 판단 사유를 기록한다.
- `sourceSnapshotImpact`: 기존 관측 데이터 읽기만 사용하며 전략 policy에서 수정·우회 수집하지 않는다.
- `executionImpact`: SHADOW 가상 체결만 변경. LIVE/PAPER 브로커 주문 경로는 변경 없음.
- `shadowLearningImpact`: 기준 표본 수집을 유지하고 조건부 전략을 별도 원장과 성과로 추가한다.
- `telegramImpact`: 없음.
- `providerImpact`: 추가 provider 호출 경로 없음. 전략 보유 종목도 동일한 기존 collector 호출에서 관측한다.
- `testsRequired`: 시간 cutoff·동일 표본·그룹·표본/일수·기간 선택·고정 예약 청산·비용·중복·재시작·원장 장애 격리·스캔 연결·화면 근거와 빈 상태·기존 기준 실험 회귀·lint 및 전체 검증.
- `rollbackPlan`: 변경 커밋을 `git revert <commit>`하고 재배포한다. 원장은 보존한다.

## Consequences

표본이 부족하면 조건부 전략은 매수하지 않지만 기준 실험은 계속 쌓인다. 단순한 4개 그룹과 탐색 기본값에는 종목 편중, 시기 편중, 상관된 표본, 기간 선택에 따른 과적합 가능성이 남는다. 최근 뉴스가 없다는 분류는 collector가 보유한 관측 범위에서의 부재이며 전체 시장의 뉴스 부재를 보장하지 않는다. 뉴스·추세별 성과는 인과관계의 증명이 아니다.

예약 종가 체결은 가상 체결 가정이다. 실주문의 체결 가능성·유동성·슬리피지 오차는 이 실험에서 검증하지 않으며 LIVE 자동 적용도 하지 않는다. 예약일 종가 관측이 늦으면 완료 표시가 늦어질 수 있으나 유효 시각과 발견 시각을 구분해 표시한다.

예약 거래일은 진입 시 KRX 달력 SSOT로 계산해 고정한다. 복원 검증은 저장한 예약일의 유효한 날짜·15:30 KST 시각·진입 이후 순서와 청산 메타데이터를 확인하며, 이후 수정된 휴장일 달력으로 과거 예약일을 다시 계산하지 않는다. 사후 달력 변경만으로 이미 승인된 원장 전체가 읽기 불능이 되거나 예약일이 이동해서는 안 된다.

## Alternatives Considered

- 기준 실험에 뉴스·추세 필터를 넣기: 탈락 후보의 비교 표본이 사라진다.
- 과거 D5 평균만 비교하기: 기간별 표본 차이와 긴 보유 기간 우대를 구분할 수 없다.
- 현재가로 사후 청산하고 D1/D3/D5 종가 성과와 동일하다고 표시하기: 학습 목표와 체결 정의가 달라진다.
- 추세 역전이나 성과 악화에 따른 조기 매도 추가: 보유 중 상태에 조건부로 대응하는 학습 근거가 아직 없다.
- 기준 원장에 전략을 넣기: 전략 원장 손상이 기준 실험 저장과 복원까지 중단할 수 있다.
- LIVE 자동 적용: 이번 SHADOW 구현 범위를 넘으며 별도 검증과 실행 경계 설계가 필요하다.
