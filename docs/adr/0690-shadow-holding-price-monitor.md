# ADR-0690: Shadow 보유 가격 독립 감시

Status: Accepted · 2026-10-03

전체 종목의 가격·일봉·수급·재무 수집이 끝나야 보유 매도를 판단하던 지연을 줄인다.

- 장중 30초 cron으로 보유 및 청산 후 비교 관측 종목의 KIS 현재가만 수집한다. 별도 `quoteOnly` PaperSnapshot을 생성하며 정책 내부 공급자 조회는 없다.
- 5개 동시 요청, 25종목 묶음마다 최신 전략 원장을 읽고 판단·핵심 원장·상세 측정·추천 후속 기록을 저장한다. 전체 스캔도 네트워크 수집 후 최신 원장을 다시 읽는다. 읽기부터 핵심 저장까지 동기 실행으로 중복 청산·과거 원장 복원을 막는다.
- 회차당 20초 작업 예산 이후 새 묶음을 시작하지 않는다. 진행 중 요청은 기존 KIS timeout을 따르므로 20초는 강제 종료 시각이 아니다. 겹친 호출은 합치고 오래 확인하지 않은 종목부터 순환한다. 첫 회차 동률에서는 신규 관측형 보유를 우선한다.
- 현재가 감시는 동결된 손실 제한·수익 반납 정책과 비교 연구에 새 가격을 공급한다. 지표가 없는 가격 전용 관측은 신호 약화 누적을 초기화하거나 신호 약화 매도를 발동하지 않는다. 신규 매수·지표 재선택·신호 약화·기존 예약 종가 청산은 전체 스캔이 계속 담당한다.
- 휴장·장외·명시적 일시정지에는 수집하지 않는다. 진행 중 일시정지·장마감이 발생하면 결과를 매매 판단에 적용하지 않는다. 기존 실주문 경로는 연결하지 않는다.
- 거래 원장의 매도 이벤트를 기존 Telegram 발송 경로가 읽는다. 별도 직접 전송은 없다. 장중 요약은 전체 스캔 이후 완료된 보유 감시 결과도 허용한다.
- 대시보드/API에 회차 완료·소요·성공/시도 종목 수·매도 수·60초 초과/미확인 보유 수를 표시한다. 30초는 실행 주기이며 모든 종목의 갱신 간격 보장은 아니다. 프로세스 재시작 시 감시 실행 상태는 초기화되며 실제 거래·측정 원장은 보존된다.

검증: 가격 식별/시각/장시간, 중복 호출, 순환 공정성, 장애 후 재개, 수집 중 정지, 전체 스캔과 청산 경합, 손절/트레일링·과거 가격 거부·신호 근거 보존, 측정 저장, Telegram 장중 요약 회귀 테스트.

복구: 독립 감시 cron을 제거하면 전체 스캔의 기존 판단이 계속 작동한다. 이미 기록한 매도와 측정은 삭제하거나 되돌리지 않는다.

2026-10-06 보완(사용자 요청): 순환은 관측 매도 보유 종목을 D5 대조용 청산 종목보다 먼저 조회하고, 같은 그룹 안에서만 오래 확인하지 않은 순서를 따른다. 묶음은 30종목이며 KIS 관심종목(멀티종목) 시세조회(FHKST11300006) 1회로 현재가를 받는다. 실전 데이터 키가 없거나 응답이 비면, 또는 응답에서 빠진 종목은 기존 5개 동시 단건 현재가 조회(FHKST01010100)를 쓴다. 관측 시각(요청 시작)·출처 표기·신선도 검사·손실 제한 기준·KIS 호출 우선순위(LOW)는 바꾸지 않는다. 복구: 가격 수집기의 묶음 조회를 빼면 단건 조회로 돌아간다.
