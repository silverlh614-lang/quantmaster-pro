# ADR-0673 — 운영 레짐 제거

상태: Accepted · 2026-09-13

사용자는 새 모델에서 레짐 자체를 제거하고, 매매 시그널과 학습·연구는 계속 유지하도록 지시했다. 2026-09-13 추가로 “승인 live , paper에서 더이상 레짐, kelly는 사용하지 않는다 완전히 없앤다”라고 승인했다. 기존 구현은 Shadow 진입에서만 분리하고 백그라운드 분류·경고·정책 갱신을 남겨 지시를 충족하지 못했다.

- 후속 사용자 지시: 기존 KIS 연결·호가·가상체결 방식을 유지하고 당장 LIVE로 전환하지 않는다. 남은 구 레짐 발굴 호출을 현행 관측·추천·시그널·학습으로 정리하되 KIS 어댑터·체결·주문 안전의 별도 개편으로 확대하지 않는다.
- 시장 레짐 분류, 현재 레짐 조회, 전이 저장, Bear/IPS 경고와 레짐·Kelly 정책 갱신을 운영 경로에서 제거한다. 과거 원장·재현 계산은 보존하지만 중립 R4를 반환하거나 새로운 우회 flag로 정책을 되살리지 않는다.
- KIS 지수·시장 폭·가격·뉴스·수급·VIX 원자료 수집은 유지한다. 두 R6 수집 flag를 없애고 거래일·시각 신선도 검증은 항상 수행한다. 데이터 공급자 실패를 시장 신호로 해석하지 않는다.
- 기존 새 모델의 가상체결은 KIS REST 현재가·일봉에 기반한 내부 원장 기록이다. KIS 모의투자 서버 주문이나 호가 잔량·부분체결 모사는 이번 변경에 포함하지 않는다. 인증·서버 선택·가격 API·체결 조회·가상체결 비용 계산은 기존 구현을 유지한다.
- Paper 관측은 정적·동적 후보군, 워치리스트, 뉴스와 기존 열린 실험을 직접 합쳐 단일 Snapshot으로 수집한다. 구 레짐/Gate 스크리닝 통과가 관측 자격이 되지 않는다. 진입·청산 시그널, D1/D3/D5 성과, 연구와 4채널 전송을 유지한다.
- 예전 레짐 저장 API는 410으로 종료하고 상태 조회는 현재 Paper 결과를 표시한다. `/now`와 `/status`는 현재 관측·전략·봇 상태를 사용한다. 레짐 전용 명령은 폐기를 안내한다.
- 기존 원장의 실제 가격 기반 손절·목표·잔량 관리, 실체결 확인, OCO, 비상정지와 주문 중복 방지 경계는 보존한다. 구 LIVE/PAPER 레짐 자동 진입과 R6 긴급청산·레짐별 손절 조정도 사용자 추가 승인에 따라 폐기한다. 공용 scanDispatcher 진입점은 모든 모드에서 현행 관측·전략 시그널로 연결한다. 가상 체결을 실제 주문으로 자동 승격하지 않으며 기존 체결·OCO·가격 손절·계좌 안전은 유지한다.
- 현재 배포 대상은 SHADOW 운영이다. 구 LIVE/PAPER 오케스트레이터의 autoPopulateWatchlist·scanAndUpdateIntradayWatchlist 호출 교체는 후속 작업으로 남긴다. 현재 SHADOW 일정에서는 이 오케스트레이터를 실행하지 않는다. 폐기한 레짐 API는 중립값을 합성하지 않고 오류를 반환하므로, 향후 LIVE/PAPER 운영을 열기 전에 이 두 경로의 전환과 검증을 완료해야 한다.
- 검증: 폐기 API의 분류·전이저장·알림 부작용 0, 원자료 수집/시각 검증, 후보가 없는 구 워치리스트에서도 새 관측, 시그널·학습·봇 회귀, lint 및 저장소 검증. Railway에서는 코드 배포 후 관련 변수 19개를 제거하고 실행 모드·작업 등록·최근 관측·봇 건강을 확인한다.
- 테스트 재현 범위: 현재 resolver의 폐기 오류와 부작용 부재를 실제 모듈로 검증한다. 현재 공용 스캔에서 사용하지 않는 구 preflight·emptyScan 통계는 테스트 내부의 과거 Snapshot fixture로만 재현하며 운영 fallback으로 복구하지 않는다.
- 복구: 코드 커밋 revert 및 Railway 배포 rollback. 과거 거래·연구·가격·메시지 원장을 삭제하지 않는다.
