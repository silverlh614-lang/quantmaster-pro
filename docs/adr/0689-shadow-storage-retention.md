# ADR-0689 — Shadow 상세 관측 자동 정리

- Date: 2026-10-03
- Status: Accepted

## Context

기본 관측과 가상 거래가 계속 쌓인다. 사용자는 불필요한 장기 저장을 줄이되 추천·진입·매도 근거와 학습 결과를 보존하는 자동 정리를 승인했다.

## Decision

- 기존 직렬 Shadow 스캔의 장외 실행에서 한국 날짜별 하루 한 번 정리한다. 수집·학습보다 먼저 실행하되 정리 실패는 관측을 막지 않고 상태에 표시한다. 하루 월별 파일 2개 압축, 상세 배치 최대 1,000개 검사로 작업량을 제한하고 커서로 다음 구간을 이어간다.
- 이전 달의 완료 기본 관측을 gzip으로 무손실 압축한다. 복원 내용이 원본과 일치하는지 재확인한 뒤 평문 중복만 지운다. 두 파일이 남은 중단 상태는 동일할 때만 합치고 충돌은 보존·보고한다. 저장·조회·재시작 모두 압축 파일을 지원한다.
- 상세 가격 경로는 90일보다 오래되고, 포함 거래가 모두 청산되었으며 청산 후 비교 연구까지 완료된 배치만 삭제한다. 최근 60개 기본 관측 진입일, D1/D3/D5 각 평가 진입일, 전략 진입일, 매도 연구 완료 진입일을 각각 보호한다. 진입·청산·연구 완료·최근 관측 시각도 모두 90일 밖이어야 한다. 수익률로 삭제 대상을 고르지 않는다.
- 진행 거래, 최근 관측, 미완료 비교, 알 수 없는 거래, 손상 파일, 저장 미확인 상태, 심볼릭 링크는 삭제하지 않는다. 혼합 배치는 한 거래라도 보호 대상이면 전체 보존한다. 지정 데이터 경로 안의 정규 파일만 다룬다.
- 삭제 전후 기록을 저장하여 재시작 시 누적 건수를 복구한다. 의도적 정리는 관측 누락과 구분한다. 최근 실행 시각·누적 압축/삭제/절약 용량·보호/오류 현황은 대시보드와 읽기 전용 `/api/shadow/storage`에서 확인한다.
- 추천 원문·진입/매도 판단·동결 정책/근거·거래 요약·기본 학습 표본·매도 연구 결과·누적 성과는 삭제하지 않는다. 기존 뉴스/봇 메시지 보관 정책은 유지한다. 실주문 경로는 변경하지 않는다.

## Verification / recovery

압축 전후 원장 전체, 학습 선택, 누적 성과의 동등성 및 재시작·중단 복구를 검증한다. 진행/최근/미완료/오류/링크 보호와 실제 대상 삭제를 테스트한다. 무손실 월별 압축은 복원 가능하다. 삭제한 상세 가격 경로는 복원되지 않지만 핵심 거래 근거와 요약·학습 결과는 남는다. 원장 전체 크기의 영구 상한을 보장하는 정책은 아니며, 핵심 표본 자체 삭제는 별도 근거 재현 설계가 필요하다.
